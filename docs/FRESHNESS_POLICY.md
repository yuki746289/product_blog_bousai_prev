# 情報鮮度管理方針

## 1. 基本方針

防災情報では「リンクが生きていること」と「内容が現在も正しいこと」を分けて管理する。

### 自動確認

- 再確認期限の到来
- 必須管理項目の欠落
- 公開ブロッカー残存
- 将来拡張: 出典URLのHTTP状態
- 将来拡張: 出典ページの更新検知

### 人による確認

- 公的機関の推奨内容が実質的に変わったか
- 災害時の行動説明が最新のガイダンスと一致するか
- 商品比較が現在も妥当か
- 表現が過度な断定になっていないか

## 2. 再確認間隔

全記事に一律日数を強制せず、内容に応じて `next_review_at` を設定する。

- 高リスク安全情報: 短い間隔
- 制度・行政情報: 改定時および定期再確認
- 商品情報: 商品入替・仕様変更を考慮して定期再確認
- 一般的な備え: 比較的長い間隔でもよいが出典は定期確認

## 3. バッチ

鮮度確認バッチは毎日実行してよい。
バッチは記事内容の正しさを自動保証せず、「確認対象を漏らさない」ために使用する。

## 4. 公開停止

以下では必要に応じて `SUSPENDED` とする。

- 主要出典が削除され代替一次情報が確認できない
- 行政・公的機関の指針変更が疑われる
- 安全性に関する記述の妥当性が確認できない
- 商品の重要仕様が不明になった
