# ユーザー作業手順：キーワード調査データの取得

更新日: 2026-09-03

この手順は、ChatGPT側で検索意図のクラスタリング、既存記事との重複確認、記事候補化を行うために、ユーザーが最低限取得するデータを定義する。

## 1. 最初に行う作業

まずラッコキーワードで次の基点キーワードを検索する。

初回は以下の8語を対象とする。

1. 防災リュック
2. 携帯トイレ
3. 非常食
4. 停電 対策
5. 台風 対策
6. 車 水没
7. ポータブル電源 防災
8. 防災グッズ

一度に全部行う必要はない。
まず2〜3語ずつ取得して共有してもよい。

## 2. ラッコキーワードでの取得手順

1. ラッコキーワードへログインする。
2. 検索欄へ基点キーワードを入力する。
3. サジェストキーワード取得を実行する。
4. 検索結果が表示されたら、画面右上の「データ出力」を選ぶ。
5. 出力形式は次の優先順とする。
   1. JSON（AI向け）
   2. CSV
   3. コピー
6. ダウンロードしたファイルを加工せず、そのままChatGPTへ添付する。
7. ファイル名は変更しなくてよい。

無料プラン等で月間検索数・SEO難易度が空でも問題ない。
初回の目的は、検索者がどのような疑問・言い回しで検索しているかを把握すること。

## 3. 可能なら追加で取得するデータ

同じ基点キーワードで「よくある質問検索」または質問系の検索結果が取得できる場合は、同様にJSONまたはCSVで出力して共有する。

優先度:

- サジェスト: 必須
- よくある質問: 可能なら取得
- 月間検索数: 後からでもよい
- SEO難易度: 補助指標なので必須ではない

## 4. ChatGPT側で行う作業

ファイル受領後、ChatGPT側で以下を行う。

1. 複数ファイルを統合
2. 重複キーワードを除去
3. 表記違いを整理
4. 検索意図でクラスタリング
5. 既存30記事・Q&A・商品記事と照合
6. 次の5分類へ振り分け
   - 既存記事強化
   - 新規記事
   - Q&A追加
   - 商品記事・商品導線強化
   - 見送り
7. Google Trendsで季節性を確認
8. 実際のGoogle検索結果（SERP）で検索意図と競合を確認
9. 優先順位を付ける
10. 新規記事候補はpillar/detail/practical/product構造へ配置する

## 5. Google Keyword Plannerは後でよい

Keyword Plannerは初回調査の必須作業にしない。

ラッコキーワードで候補が多く出た後、優先候補の検索需要を比較したい場合に使用する。

必要になった場合のみ、ユーザー側でGoogle AdsのKeyword Plannerから候補キーワードの月間検索数等を取得し、CSV等で共有する。

## 6. Search Consoleは現在は待機

サイト公開直後はSearch Consoleの検索パフォーマンスデータが十分ではないため、現時点ではキーワード調査の主データとして使わない。

表示回数・クリック・CTR・平均掲載順位が蓄積した後に、既存記事のリライト判断へ利用する。

## 7. ユーザー側で今すぐ必要な作業

現時点では次の1点だけでよい。

**ラッコキーワードで2〜3個の基点キーワードを検索し、JSON（AI向け）またはCSVをそのままChatGPTへ添付する。**

最初のおすすめ:

1. 防災リュック
2. 携帯トイレ
3. 非常食

この3語は既存の防災入門・備蓄・商品記事と接続しやすく、既存記事強化と新規記事候補の両方を発見しやすい。
