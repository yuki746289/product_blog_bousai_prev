# 防災くらしガイド サイト個別レビュー・プロファイル

更新日: 2026-09-04

## 1. 目的

本ファイルは `docs/COMMON_SITE_REVIEW_FRAMEWORK.md` を、防災サイト「防災くらしガイド」へ適用するためのサイト個別設定である。

共通専門家視点を削除せず、各視点を `REQUIRED / CONDITIONAL / N/A` で明示する。

## 2. サイト基本プロファイル

```yaml
site_review_profile:
  site_name: 防災くらしガイド
  site_purpose: 日本の一般生活者向けに、防災準備・災害時判断・備蓄・関連商品の選び方を分かりやすく提供する
  primary_audience: 日本国内の一般生活者
  primary_conversion: 安全な行動理解、関連記事・公的情報への遷移、必要時のみ商品比較・Amazon導線
  risk_level: HIGH
  persona_mode: SITUATIONAL_SEGMENT
  detailed_persona: N/A
```

## 3. ペルソナ設定

### 現在の方針

詳細な架空ペルソナは **N/A** とする。

理由:

- 防災では、架空の年齢・年収・職業・家族構成を固定するより、災害種別・居住環境・家族状況・避難状況・停電等の**状況と制約**が必要情報を大きく左右する。
- 根拠のない詳細ペルソナは、対象読者を不必要に狭める可能性がある。
- 高齢者、乳幼児、ペット、車利用、マンション等は「属性の決めつけ」ではなく、必要情報が変わる状況セグメントとして扱える。

代替として、CR-13の以下を必須とする。

- `target_reader`
- `usage_context`
- `knowledge_level`
- `urgency_level`（必要なページ）
- `reader_problem`
- `reader_goal`
- `page_job`
- `entry_path`
- `next_action`
- `conversion_path`
- `design_priority`

詳細ペルソナを将来導入する場合は、調査・実測データ等の根拠があり、内容・商品・導線・トーンを実際に変更する必要がある場合に限り、本プロファイルを変更する。

## 6. ページ種別ごとの適用

### 情報記事

必須:
- E01〜E08
- E11〜E14

条件付き:
- 商品導線あり → E09
- 計測・改善施策あり → E10

### 商品記事

必須:
- E01〜E09
- E11〜E14

条件付き:
- 新規計測・A/Bテスト等 → E10

### Q&A

必須:
- E01〜E08
- E11〜E14

商品導線がある場合のみE09。

### トップページ / カテゴリ / 固定ページ

必須:
- E01
- E03〜E08
- E11〜E14

防災判断・数値・公的情報を扱う部分はE02必須。

### リアルタイム防災情報

必須:
- E02
- E04〜E08
- E11〜E14

計測改善を行う場合はE10。

### 共通CSS / JS / ビルド / 更新ワークフロー

必須:
- E05
- E07
- E11
- E12
- E14

導線変更時はE06、計測変更時はE10を追加。

## 7. 防災サイト固有の優先順位

1. 人命・安全・重大な誤判断の防止
2. 正確性・公的根拠・情報鮮度
3. アクセシビリティ
4. 法務・権利・プライバシー
5. 読者理解・UX・情報設計
6. 日本の制度・生活文脈への適合
7. 技術的信頼性・運用保守性
8. SEO・ブランド
9. 収益・CV・グロース

## 8. 再評価トリガー

以下を追加した場合は、現在 `N/A` の視点も再評価する。

- コメント・投稿・レビュー → P17
- SNS運用・OGP最適化・外部配信強化 → P19
- 会員機能・問い合わせ・予約・購入後支援 → P22
- 調査データに基づくセグメント別LP → 詳細ペルソナ / P08

`N/A` は永久除外ではなく、現在のサイト機能に対する判定である。
