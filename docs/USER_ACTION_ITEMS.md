# ユーザー側確認・対応事項

更新日: 2026-09-04

## 1. 目的

ログイン済みのGoogle管理画面、実機、アカウント固有データ等、ChatGPT側だけでは完了できない確認事項を独立して管理する。

これらは忘れないよう対応事項として残すが、明示したものを除き、通常の記事作成・リポジトリ改善を停止するブロッカーにはしない。

|---|---|---|---|---|---|
| U01 | GA4 DebugView / Realtimeでイベント受信確認 | TODO | ユーザー | 任意。計測改善前には推奨 | `amazon_click` / `product_guide_click` が想定パラメータで受信されることを確認 |

## 3. 優先度

現在の優先度は次のとおり。

1. サイト改善・記事作成はChatGPT側で継続する。
2. U01〜U03・U09はユーザーが実施できるタイミングで確認する。
3. U04〜U07はデータ蓄積待ちのため、現時点で無理に実施しない。
4. U08は任意。公開SERP、Search Console、既存キーワード調査等で判断可能な場合は必須にしない。

## 4. フィードバック後の扱い

ユーザー確認で問題が見つかった場合は、ChatGPT側で以下を行う。

- 原因切り分け
- リポジトリ修正
- 必要なら共通ルール・チェックリスト更新
- 自動テスト化可能な問題は回帰テスト追加
- 本番反映・スモーク確認

単発修正だけで終わらせず、再発防止まで検討する。
