# Amazonアフィリエイト運用方針

## 1. 基本

AmazonアソシエイトのStoreIDはサイト設定で管理する。
記事では情報提供部分と商品紹介部分を明確に分ける。

## 2. 表示

アフィリエイト対象記事では、読者が広告を含む記事であることを認識できる表示を行う。
サイト共通部分にはAmazonアソシエイト参加者として必要な表示を設ける。

## 3. 商品紹介

推奨理由は販売都合ではなく、記事内で説明した課題との適合性に基づく。

確認対象:

- 商品名
- 用途
- 容量・重量・サイズ
- 電池・充電方式
- 保存期間等の仕様
- 使用上の注意
- メーカー情報
- Amazon商品ページ

価格・在庫は変動するため、初期実装では固定表示を必須としない。

## 4. 安全情報との分離

災害発生時の避難・安全判断の記事を商品購入誘導中心の構成にしない。
商品購入により安全が保証されるような表現を使用しない。


## 5. 情報記事から商品紹介ページへの導線

本サイトでは、情報記事へAmazon商品リンクを直接並べることを必須としない。

基本導線:

```text
情報記事
  ↓
用途別・テーマ別の商品紹介ページ
  ↓
Amazon商品リンク
```

商品紹介ページでは、具体商品より先に以下を説明する。

- 選ぶ基準
- 想定用途
- 重要仕様
- 向く条件・向かない条件
- 安全・保管・使用上の注意

同じ商品群を扱う場合は、記事ごとに商品一覧を複製せず、共通の商品紹介ページへ内部リンクする。


## 6. 関連商品導線の原則

情報記事を作成・更新する際は、その記事の課題解決に自然に関係する商品群があるかを確認する。

関連する場合は、原則として対応する用途別・テーマ別の商品紹介ページへの内部リンクを設ける。

例:

- 断水・備蓄 → 水・非常食、携帯トイレ・衛生用品
- 停電 → ライト・ラジオ、モバイルバッテリー・電源
- 台風・大雨 → 水・非常食、携帯トイレ、ライト・電源
- 車と災害 → 車載防災用品
- 地震・住宅 → 家具固定用品等（商品紹介ページを作成した場合）

ただし、商品との関連が弱い場合は無理にリンクしない。
保険・制度・被災後手続き等の記事では、読者の検索目的を優先し、商品導線が不要なら掲載しない。

高リスク記事では、安全行動と公的情報を先に提示し、商品導線は平常時の備えとして後段に置く。
