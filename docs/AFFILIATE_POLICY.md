# Amazonアフィリエイト運用方針

更新日: 2026-09-03

本ファイルは**商品・Amazonに固有の追加ルール**だけを定義する。
一般の記事作成、画像、UI、内部リンク、Q&Aの共通ルールは `docs/CONTENT_CREATION_RULES.md` を正とする。

適用:

- 防災グッズカテゴリ
- `content_role=product`
- 本文中で具体商品を紹介する記事

## 1. 表示・安全

- AmazonアソシエイトのStoreIDは `config/site.json` を正とする。
- アフィリエイト対象であることを読者が認識できる表示を行う。
- サイト共通部分にAmazonアソシエイト参加表示を設ける。
- 商品購入により安全が保証される表現を使わない。
- 高リスク記事では安全情報・公的情報を商品紹介より優先する。

## 2. 商品選定

最優先は**記事本文で説明した用途・課題・想定読者との適合性**。

### 2.1 基本条件

- 日本国内で継続的に購入しやすい
- メーカー・販売元・仕様情報を追跡できる
- Amazon評価は原則3.8以上を目安
- Amazonレビュー件数は原則100件以上を目安
- 容量、重量、サイズ、電源方式、保存期間等の主要仕様を確認できる
- 出所不明・仕様確認困難・誇大表現の強い商品を避ける
- 安全性に関わる商品はAmazon説明だけでなくメーカー公式・公的情報を確認する

例外を採用する場合は商品メモに理由を残す。

### 2.2 記事固有条件

- 車載用品: 車内高温、保管性、固定・携行性等
- 住宅備蓄: 収納性、保存性
- 持ち出し用品: 重量、携行性
- 電源用品: 容量、出力、充電方式、保管・安全注意
- 食品・水: 容量、保存期間、保管条件、アレルギー等

### 2.3 商品数

- 原則3〜5商品
- 数合わせをしない
- 「総合ランキング」より用途別分類を優先する
- 各商品に向く人・強み・注意点・主要仕様を書く

## 3. 鮮度・差し替え

商品確認時に記録する。

- 確認日
- Amazon商品ページまたはASIN
- メーカー公式ページ
- 主要仕様
- Amazon評価・レビュー件数（確認時点の参考）
- 在庫・販売継続状況
- 記事内の対応用途

差し替え候補:

- 長期欠品
- 終売
- 型番変更
- 仕様変更
- 評価の大幅低下
- より適合する後継品
- リコール・重要注意事項

## 4. Amazonリンク

- アソシエイトタグは `config/site.json` の `amazon_associate_tag` を正とする。
- ASINと商品名・型番が確認できた場合:
  `https://www.amazon.co.jp/dp/ASIN/ref=nosim?tag=<tag>`
- ASINが確実でない場合は、誤った類似商品へ直リンクせず商品名・型番を固定した検索リンクを使う。
- 検索リンクは「Amazonでこの商品を探す」等、検索結果であることが分かる文言にする。
- Amazonの現在価格を静的HTMLへ手入力しない。
- APIを使わない場合、メーカー公式価格・希望小売価格等、Amazon以外の明確な根拠がある価格のみ使用する。
- 価格を表示する場合は確認日・出典を記録する。
- Amazonの現在価格・在庫はリンク先で確認する旨を明記する。

## 5. 商品画像

- Amazon画像URLをASINから推測・組み立てない。
- 旧 `images-na.ssl-images-amazon.com/images/P/<ASIN>...` 形式を新規生成しない。
- Amazonが提供する画像URL・リンク機能、またはメーカーが利用を認めた画像を使用する。
- Amazon画像をダウンロードして自サイトへ無断再ホストしない。
- 第三者通販・ブログ画像は、再利用可能と確認できない限り使わない。
- 商品名、型番、容量、入数、色等と画像が一致することを確認する。
- HTMLへURLを書くだけで完了にせず、実ブラウザで404/403/ホットリンク制限を確認する。
- 画像失敗時の商品カード用フォールバックを持つ。
- 表示確認日と配信元を商品メモまたはレビュー記録へ残す。
- 商品画像は本文画像数へ加算しない。

## 6. 商品紹介の文章

文章・配置の共通原則は `CONTENT_CREATION_RULES.md` の CR-06 に従う。

追加条件:

- 商品カードを連続させすぎず、判断基準を先に理解できる構成にする。
- メリットだけでなく、記事用途に対する弱点・過剰仕様・不足仕様も書く。
- 安さだけを推奨理由にしない。

## 7. 情報記事から商品記事へのリンク

リンク位置・重複・高リスク時の優先順位は `CONTENT_CREATION_RULES.md` の CR-05B を正とする。
本ファイルでは同じルールを再掲しない。
