## 4. 深掘りクラスター

### 大雨・水害

B005を親記事とし、B008/B009/B010/B012/B020等へ接続する。

### 車と災害

B008を中心に、冠水路、駐車場所、車両保険、車載防災用品へ分岐する。

### 保険

B019を総合導線として、水災・風災・地震・自動車保険の詳細記事へ接続する。

### 地震

B007を親記事として、家具転倒、停電・断水、地震保険等へ接続する。
