# サイト・ページ構成

## 1. 基本設計

本サイトは、読者が次の3方向から目的の記事へ到達できる構造とする。

1. 災害別: 台風・大雨/水害・地震など
2. 困りごと別: 車・住宅・停電/断水・保険
3. 準備別: 防災入門・備蓄・防災グッズ

単一の記事を複数カテゴリへ無制限に所属させるのではなく、主カテゴリを1つ持たせ、関連導線で横断カテゴリへ接続する。

## 2. グローバルナビゲーション

- 防災入門
- 台風
- 大雨・水害
- 地震
- 車と災害
- 住宅と災害
- 保険・お金
- 防災グッズ
- Q&A

画面幅が狭い場合はハンバーガーメニューへ収納する。

## 3. トップページ

### 3.1 ヘッダー

- サイト名・ロゴ
- グローバルナビ
- サイト内検索
- 「公的な災害情報を確認する」導線

本サイトはリアルタイム警報サイトではないため、緊急時は気象庁・自治体等の公的情報を確認する旨を明記する。

### 3.2 ピックアップ

トップページ最上部の主要領域。

- 大カード: 1件
- 小カード: 最大3件
- 合計最大4件

選定対象は `PUBLISHED` のみ。
季節性・検索需要・社会的関心・記事品質・安全レビュー状況を基準に選ぶ。

例:

- 車が水没・冠水しそうなとき
- 大雨・浸水と火災保険
- 台風が来る前に確認したいこと
- 防災は何から始める？

### 3.3 はじめての防災

初心者向け導線。

- 防災は何から始める？
- 防災バッグ
- 水・食料・トイレ
- 家族で決めておくこと

### 3.4 災害別に備える

カード形式で以下を表示。

- 台風
- 大雨・水害
- 地震
- 停電・断水

各カテゴリは1記事へ直結させるのではなく、複数記事を持てるカテゴリ導線とする。

トップページのカテゴリカードには原則として次を表示する。

1. カテゴリ名（カテゴリページへのリンク）
2. 短いカテゴリ説明
3. 代表記事2〜3件のタイトルリンク
4. 「このカテゴリの記事をすべて見る」リンク

作成済み記事は記事ページへ直接リンクし、未作成記事は準備中リンクとしてタイトルのみ表示してよい。
カテゴリ内の記事数が増えても、トップページへ全件を並べず代表記事だけを表示する。

将来、津波・火災・大雪等を追加可能とする。

### 3.5 困りごとから探す

- 車
- 住宅
- 保険
- 被災後の手続き

「災害別に備える」と同様、各カテゴリに複数記事を持たせる。
トップページではカテゴリ名・代表記事2〜3件・カテゴリ一覧リンクを表示し、詳細はカテゴリページで整理する。

「大雨」など災害名を知らなくても、読者の現実的な困りごとから探せる構造とする。

### 3.6 防災グッズ

商品を並べるだけではなく、用途別の記事へ誘導する。

- 防災バッグ
- 携帯トイレ
- ライト・ラジオ
- モバイルバッテリー
- ポータブル電源
- 車載防災用品

### 3.7 Q&A

トップページでは「防災グッズ」の直後に配置する。
トップページには代表的なQ&Aを3〜5件表示する。
質問部分をクリックすると、ページ遷移せず同じページ内で回答の表示・非表示を切り替えられる形式とする。
HTMLの `details/summary` 等、キーボード操作でも利用しやすい実装を優先する。

トップページの回答は短くし、回答末尾に関連する詳細記事へのリンクを置く。
Q&A全件は独立したQ&A一覧ページへ掲載し、車、住宅・保険、台風・大雨、停電・断水、備蓄・防災用品等に分類する。

Q&Aは数を限定せず、読者の具体的な疑問がある限り追加してよい。
ただし通常記事の本文をそのまま複製せず、「短い回答 → 詳細記事」の入口として扱う。

### 3.8 新着・更新記事

新規公開記事と、重要な更新を行った既存記事を表示する。
「新着」と「更新」を区別する。

### 3.9 公的情報への導線

気象庁、内閣府防災、自治体等の公的情報への導線を設置する。
リアルタイム情報を自サイトで再配信しているような表現は行わない。

### 3.10 記事タイトルリンク

トップページ上で表示する記事タイトルは、タイトル文字列自体を記事ページへのリンクとする。
「記事を読む」「詳しく読む」等の補助リンクを併記してもよいが、タイトルをクリックできない状態にはしない。

### 3.11 トップページのサムネイル

トップページの記事カード・カテゴリカードには、内容を直感的に把握できる画像がある場合はサムネイルを表示する。

- 作成済み記事は、原則として記事内で採用済み・権利確認済みのヒーロー画像または代表画像を再利用してよい。
- カテゴリは、そのカテゴリを代表する記事の画像を使用してよい。
- トップページやカテゴリ一覧でのサムネイル再利用は「別記事への写真使い回し」とは扱わない。
- 同じ画面で同じ画像が過度に連続しないようにする。
- 未作成記事・カテゴリに適切な画像がない場合は、無理にサムネイルを付けない。
- サムネイルは装飾ではなく、記事・カテゴリ内容を識別しやすくする目的で使用する。

### 3.12 フッター

- [運営方針](../preview/about.html)
- [免責事項](../preview/disclaimer.html)
- [プライバシーポリシー](../preview/privacy.html)
- [広告について](../preview/advertising.html)
- Amazonアソシエイト参加表示
- 公的情報へのリンク

固定ページは記事数とは別枠で管理する。リンク先が存在しない状態で `href="#"` を置いたまま公開しない。

## 4. カテゴリページ

カテゴリページは単なる記事一覧にしない。

構成:

1. カテゴリの概要
2. まず読む記事
3. 状況別・テーマ別の詳細記事
4. 関連する防災グッズ
5. 関連カテゴリ
6. 更新された記事

カテゴリページでは記事を役割・テーマごとにグループ化し、単純な時系列一覧にしない。
未作成記事も初期設計の把握に必要な場合は「準備中」としてタイトルリンクだけ表示してよい。
作成済みになった時点で実記事URLへ差し替える。

例: 「大雨・水害」

- 水害の基本
- 自宅の浸水
- 車の冠水・水没
- 避難と安全
- 保険
- 停電・断水
- 防災用品

## 5A. Q&Aページ

Q&Aページは、読者の自然な質問文を入口として詳細記事へ案内する。

基本構成:

1. Q&Aページ概要
2. Q&Aカテゴリ内リンク
3. カテゴリ別Q&A
4. 各質問の開閉式回答
5. 回答末尾の関連詳細記事リンク
6. 公的情報・詳細記事を優先する旨の注意

1件の回答は原則として短くまとめ、条件・例外・根拠の詳細は通常記事へ委ねる。
高リスク、安全行動、保険・制度に関するQ&Aは断定を避け、既存の確認済み記事・公的情報と整合させる。
同じ質問への回答をQ&Aと通常記事で別々に管理して内容が矛盾しないようにする。

## 5. 記事ページ

### 5.1 基本構成

- パンくず
- タイトル
- 要約
- 最終確認日
- 必要に応じて広告表示
- 結論/重要ポイント
- 本文
- チェックリスト・表・図
- 関連する公的情報
- 関連記事
- 必要な場合のみ商品紹介
- 更新履歴

### 5.2 高リスク記事

避難・脱出・応急対応等では、商品紹介より先に安全情報と公的情報への導線を置く。

### 5.3 車関連記事の横断導線

車に関する記事では、本文の主題を邪魔しない範囲で次の関連導線を検討する。

- 車両の災害被害と保険（例: B011 水没車と車両保険）
- 車載防災用品（例: B029 車に積んでおきたい防災用品）
- 関連する大雨・台風・地震のpillar記事

特に冠水・水没・駐車場所などの車系記事では、「安全行動 → 被害後の保険確認 → 平常時の車載備蓄」へ移動できる構成を基本とする。
未作成記事は準備中リンクとして表示し、完成後に実記事URLへ差し替える。

### 5.4 商品が関連する記事の横断導線

車に限らず、記事内容に防災用品・備蓄品等が自然に関連する場合は、対応する商品紹介ページへの導線を設ける。

基本例:

- 水・備蓄 → 水・非常食の商品紹介
- 断水 → 携帯トイレ・衛生用品の商品紹介
- 停電 → ライト・ラジオ、モバイルバッテリー・電源の商品紹介
- 台風・大雨 → 水・食料、トイレ、照明、電源等の関連商品紹介
- 車 → 車載防災用品
- 地震・住宅 → 家具固定等の関連商品紹介ページを作成した場合に接続

商品リンクは本文中の関連箇所または記事後半の関連導線へ置く。
高リスク記事では、安全行動・公的情報を優先し、商品導線は平常時の備えとして後段に置く。
商品との関連が弱い記事には無理に追加しない。

## 6. URL案

- `/guide/` 防災入門
- `/typhoon/` 台風
- `/flood/` 大雨・水害
- `/earthquake/` 地震
- `/vehicle/` 車と災害
- `/home/` 住宅と災害
- `/insurance/` 保険・お金
- `/goods/` 防災グッズ

記事URLはカテゴリ配下の固定slugとし、後からタイトルを変更してもURLを原則変更しない。

## 7. 固定ページ

固定ページは記事IDを付与せず、サイト運営・信頼性・法的表示のための共通ページとして管理する。

| ページ | プレビュー | 役割 |
|---|---|---|
| 運営方針 | `preview/about.html` | 編集・安全・商品選定・更新方針 |
| 免責事項 | `preview/disclaimer.html` | 情報利用上の前提・責任範囲 |
| プライバシーポリシー | `preview/privacy.html` | Analytics・Cookie・外部サービス等 |
| 広告について | `preview/advertising.html` | Amazonアソシエイト・広告方針 |
| お問い合わせ | `preview/contact.html` | 受付窓口を公開するときのみ表示。受付停止中は `noindex` のまま非表示 |

記事本数を増やすことより、必要な固定ページ・カテゴリ・Q&A・共通導線が不足していないことを優先する。
