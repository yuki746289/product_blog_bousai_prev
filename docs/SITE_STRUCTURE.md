# サイト・ページ構成

## 1. 基本設計

本サイトは、読者が次の3方向から目的の記事へ到達できる構造とする。

1. 災害別: 台風・大雨/水害・地震など
2. 困りごと別: 車・住宅・停電/断水・保険
3. 準備別: 防災入門・備蓄・防災グッズ

単一の記事を複数カテゴリへ無制限に所属させるのではなく、主カテゴリを1つ持たせ、関連導線で横断カテゴリへ接続する。

## 2. グローバルナビゲーション

- 防災入門
- 台風
- 大雨・水害
- 地震
- 車と災害
- 住宅と災害
- 保険・お金
- 防災グッズ

画面幅が狭い場合はハンバーガーメニューへ収納する。

## 3. トップページ

### 3.1 ヘッダー

- サイト名・ロゴ
- グローバルナビ
- サイト内検索
- 「公的な災害情報を確認する」導線

本サイトはリアルタイム警報サイトではないため、緊急時は気象庁・自治体等の公的情報を確認する旨を明記する。

### 3.2 ピックアップ

トップページ最上部の主要領域。

- 大カード: 1件
- 小カード: 最大3件
- 合計最大4件

選定対象は `PUBLISHED` のみ。
季節性・検索需要・社会的関心・記事品質・安全レビュー状況を基準に選ぶ。

例:

- 車が水没・冠水しそうなとき
- 大雨・浸水と火災保険
- 台風が来る前に確認したいこと
- 防災は何から始める？

### 3.3 はじめての防災

初心者向け導線。

- 防災は何から始める？
- 防災バッグ
- 水・食料・トイレ
- 家族で決めておくこと

### 3.4 災害別に備える

カード形式で以下を表示。

- 台風
- 大雨・水害
- 地震
- 停電・断水

将来、津波・火災・大雪等を追加可能とする。

### 3.5 困りごとから探す

- 車
- 住宅
- 保険
- 被災後の手続き

「大雨」など災害名を知らなくても、読者の現実的な困りごとから探せる構造とする。

### 3.6 防災グッズ

商品を並べるだけではなく、用途別の記事へ誘導する。

- 防災バッグ
- 携帯トイレ
- ライト・ラジオ
- モバイルバッテリー
- ポータブル電源
- 車載防災用品

### 3.7 新着・更新記事

新規公開記事と、重要な更新を行った既存記事を表示する。
「新着」と「更新」を区別する。

### 3.8 公的情報への導線

気象庁、内閣府防災、自治体等の公的情報への導線を設置する。
リアルタイム情報を自サイトで再配信しているような表現は行わない。

### 3.9 フッター

- 運営方針
- 免責事項
- プライバシーポリシー
- 広告・Amazonアソシエイト表示
- お問い合わせ
- 公的情報へのリンク

## 4. カテゴリページ

カテゴリページは単なる記事一覧にしない。

構成:

1. カテゴリの概要
2. まず読む記事
3. 状況別・テーマ別の詳細記事
4. 関連する防災グッズ
5. 関連カテゴリ
6. 更新された記事

例: 「大雨・水害」

- 水害の基本
- 自宅の浸水
- 車の冠水・水没
- 避難と安全
- 保険
- 停電・断水
- 防災用品

## 5. 記事ページ

### 5.1 基本構成

- パンくず
- タイトル
- 要約
- 最終確認日
- 必要に応じて広告表示
- 結論/重要ポイント
- 本文
- チェックリスト・表・図
- 関連する公的情報
- 関連記事
- 必要な場合のみ商品紹介
- 更新履歴

### 5.2 高リスク記事

避難・脱出・応急対応等では、商品紹介より先に安全情報と公的情報への導線を置く。

## 6. URL案

- `/guide/` 防災入門
- `/typhoon/` 台風
- `/flood/` 大雨・水害
- `/earthquake/` 地震
- `/vehicle/` 車と災害
- `/home/` 住宅と災害
- `/insurance/` 保険・お金
- `/goods/` 防災グッズ

記事URLはカテゴリ配下の固定slugとし、後からタイトルを変更してもURLを原則変更しない。
