# Q&A 出典確認メモ

確認日: 2026-09-01

## 車と災害

### QA-CAR-001 浸水車の始動禁止
- 国土交通省「浸水・冠水被害を受けた車両のユーザーの方へ」
- https://www.mlit.go.jp/jidosha/jidosha_fr09_000100.html
- 使用: 水に浸った車は自分でエンジンをかけない、HV/EV高電圧部へむやみに触らない。

### QA-CAR-002 冠水路の水深
- 国土交通省「水深が床面を超えたら、もう危険！」
- https://www.mlit.go.jp/jidosha/carinf/rcl/carsafety_sub/carsafety033.html
- JAF「冠水路走行テスト」
- https://jaf.or.jp/common/safety-drive/car-learning/user-test/disaster/waterway-driving
- 使用: 床面以下でも巻き上げ水による停止リスク。30cm等の試験値を実道路の安全基準にしない。

### QA-CAR-003 脱出用ハンマー
- 国土交通省「台風の前に車両からの脱出手順の確認を！」
- https://renrakuda.mlit.go.jp/renrakuda/carsafety035.html
- JAF「自動車が水没したときの対処と脱出方法」
- https://jaf.or.jp/common/kuruma-qa/category-trouble/subcategory-support/faq270
- 使用: ハンマー常備、手の届く位置、一部サイドガラスの合わせガラス注意。

### QA-CAR-004 水害と車両保険
- 日本損害保険協会「風水雪災等による損害を補償する損害保険」
- https://www.sonpo.or.jp/insurance/shizen/index.html
- 使用: 車両保険の台風・洪水等、地震・噴火・津波の原則除外と特約。
