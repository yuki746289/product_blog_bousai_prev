# B013 公的・業界出典メモ

確認日: 2026-09-01
次回確認予定: 2027-03-01

## F-B013-001 火災保険の建物・家財
出典: 日本損害保険協会「火災保険」
URL: https://www.sonpo.or.jp/insurance/kasai/index.html
確認:
- 建物と家財は分けて契約
- 建物のみ契約し家財を契約していないケースに注意
- 賃貸住宅では入居者が家財を契約する考え方

## F-B013-002 豪雨時の水災補償例
出典: 日本損害保険協会「平成30年7月豪雨による災害に伴う損害保険の補償内容等について」
URL: https://www.sonpo.or.jp/news/notice/2018/1807_01.html
確認:
- 台風・豪雨損害は契約内容によって異なる
- 洪水・土砂崩れ等は水災補償がセットされている場合に補償される例
- 建物・家財それぞれの例
- 契約タイプで異なるため現在の契約内容・保険会社へ確認

## F-B013-003 被害後の写真
出典: 日本損害保険協会
URL: https://www.sonpo.or.jp/news/notice/2018/1809_05.html
確認:
- 安全・防犯上必要なら片付けや修理を進めてよい
- 可能な限り損傷箇所を撮影
- 建物・家財の全体、浸水高さ・損傷箇所が分かる写真を案内

## F-B013-004 火災保険の自然災害補償
出典: 日本損害保険協会 Q&A
URL: https://soudanguide.sonpo.or.jp/home/q050.html
確認:
- 風災等と水災の補償範囲は保険種類で異なる
- 建物と家財を別々に契約

## F-B013-005 契約内容の見直し
出典: 金融庁「保険を契約している方へ」
URL: https://www.fsa.go.jp/ordinary/insurance.html
用途: 契約内容・補償の確認を促す根拠。

## F-B013-006 ハザードマップ
出典: 国土地理院・国土交通省
URL: https://disaportal.gsi.go.jp/
用途: 自宅の洪水・高潮・土砂等のリスク把握。

## 断定しない事項

- 個別契約の保険金支払可否
- 「床上浸水なら必ず支払われる」等の一律基準
- 特定の免責金額・損害割合を一般化すること
- ハザードマップ上の色だけで水災補償の要否を断定すること
- 特定商品・保険会社への加入推奨
