# B013 公的・業界出典メモ

確認日: 2026-09-01
次回確認予定: 2027-03-01

## F-B013-001 水災への備え
出典: 日本損害保険協会
URL: https://www.sonpo.or.jp/report/publish/bousai/suisai.html
確認: 洪水だけでなく内水氾濫、高潮、土砂崩れ等。火災保険に水災補償を付けることで対象とできる商品がある。

## F-B013-002 火災保険の補償範囲
出典: 日本損害保険協会 Q&A
URL: https://soudanguide.sonpo.or.jp/home/q051.html
確認: 火災保険の種類により補償範囲は異なる。洪水による床上浸水等を対象とする商品もある。

## F-B013-003 風水雪災等
URL: https://www.sonpo.or.jp/insurance/shizen/index.html
確認: 水災を含む商品がある。支払条件・免責等は商品ごとに異なる。

## F-B013-004 契約内容の見直し
出典: 金融庁「保険を契約している方へ」
URL: https://www.fsa.go.jp/ordinary/insurance.html
確認: 自然災害に備え、既加入者も補償対象・内容が十分か見直すよう案内。

## F-B013-005 水災リスクの種類
出典: 金融庁「火災保険水災料率に関する有識者懇談会」
URL: https://www.fsa.go.jp/singi/suisai/houkokusyo.pdf
確認: 外水氾濫だけでなく、内水氾濫、土砂災害、高潮等を含む。

## 断定しない事項
- 一律の支払基準
- 一律の浸水深・損害割合
- 個別契約の補償可否
- 保険加入・変更の個別推奨
