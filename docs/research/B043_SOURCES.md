# B043 一次情報メモ

確認日: 2026-09-05

## F-B043-001 気象庁「高潮に関する防災気象情報の活用」

- 高潮は台風・発達した低気圧で短時間に潮位が急上昇することがある。
- 潮位上昇より先に暴風が始まり、屋外への立退き避難が困難となる場合がある。
- 暴風が吹き始める段階までに、予想最高潮位等に応じた安全な場所への避難完了が重要。
- 警戒レベル4までに危険な場所から避難する考え方。

URL: https://www.jma.go.jp/jma/kishou/know/ame_chuui/ame_chuui_p8-3.html

## F-B043-002 気象庁「新たな防災気象情報について（令和8年〜）」

- 2026年5月29日から高潮情報を警戒レベルに対応した名称へ整理。
- レベル2高潮注意報、レベル3高潮警報、レベル4高潮危険警報、レベル5高潮特別警報。

URL: https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html

## F-B043-003 気象庁「高潮に関する情報の改善」

- 令和8年度から高潮予報海岸で波の打上げを考慮した共同予報・警報を運用。
- レベル4高潮危険警報、レベル5高潮特別警報の基準を整備。

URL: https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/pdf/stormsurge_info2026.pdf

## F-B043-004 内閣府「避難情報に関するガイドライン（令和8年3月改定）」

- 高潮を含む2026年新防災気象情報の活用方法を反映。
- 警戒レベル4までに危険な場所から避難する考え方。

URL: https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/

## F-B043-005 気象庁「潮汐・海面水位の知識」

- 高潮は気圧低下による吸い上げ効果と風による吹き寄せ効果等で海面が異常上昇する現象。
- 津波とは原因が異なる。

URL: https://www.data.jma.go.jp/kaiyou/db/tide/knowledge/tide/yougo.html

## 独自数値を置かない項目

- 満潮の何時間前なら安全か
- 潮位何cmなら個人が避難するか
- 海岸から何km離れれば安全か
- 何階なら安全か

自治体の高潮ハザードマップ、避難情報、気象庁の予報・警報を優先する。
