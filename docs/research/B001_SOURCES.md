# B001 公的出典・ファクトメモ

確認日: 2026-09-01
次回確認予定: 2027-03-01
記事: B001「防災は何から始める？家庭で最初に確認したい基本項目」

## F-B001-001 事前の備え

出典: 内閣府「令和8年版 防災白書｜特集 第3章 第4節 4-2 国民一人一人の事前の備えについて」
URL: https://www.bousai.go.jp/kaigirep/hakusho/r08/honbun/t1_3s_04_02.html

確認事項:
- 食料・飲料水は最低3日分、できれば1週間分が望ましい。
- 非常持ち出し品を事前に準備する。
- ハザードマップ、避難場所、避難経路を確認する。
- 家具・家電の固定、配置の見直しが重要。

## F-B001-002 家庭向けチェック

出典: 内閣府「自然災害への備えは万全ですか？チェックしてみよう！」
URL: https://www.bousai.go.jp/kyoiku/hokenkyousai/check.html

確認事項:
- 市区町村等が公表する災害リスク情報を確認する。
- 飲料水は1人1日3リットルの目安。
- 最低3日間、できれば1週間の備蓄。
- ローリングストックの活用。
- 非常持ち出し品の例。
- 家族・親族で安否確認方法や集合場所を確認する。

## F-B001-003 2026年度防災週間

出典: 内閣府「令和8年度『防災週間』及び『火山防災の日』について」
URL: https://www.bousai.go.jp/kyoiku/week/r8bousaiweek.html

確認事項:
- 非常用持出品の準備。
- 最低3日、できれば1週間程度の食料・飲料水・携帯トイレ・簡易トイレ等の備蓄。
- ライフライン途絶への対応確認。
- 家族内の安否確認方法。
- 家具・家電製品等の固定や配置見直し。

## F-B001-004 ハザードマップ

出典: 国土交通省・国土地理院「ハザードマップポータルサイト 利用規約」
URL: https://disaportal.gsi.go.jp/hazardmap/copyright/copyright.html
ポータル: https://disaportal.gsi.go.jp/

確認事項:
- 重ねるハザードマップは各機関の災害リスク情報をまとめて確認するためのサイト。
- 最新かつ詳細な情報は各市町村が作成するハザードマップを確認するよう案内されている。
- 地図表示や住所検索には誤差があり得る。

## 記事で意図的に断定しない事項

- 個別家庭に必要な携帯トイレの具体的個数
- 個別地域でどこへ避難すべきか
- 災害発生時の具体的な避難開始時刻
- 医薬品の具体的な備蓄方法

これらは別記事または自治体・専門機関の最新情報へ委ねる。
