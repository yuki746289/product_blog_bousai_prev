# B047 一次情報メモ

確認日: 2026-09-05

## F-B047-001 厚生労働省「災害時における健康管理」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/tiiki/saigai_00001.html
- 災害時、避難所の気温上昇や片付け作業で熱中症へ注意。
- 停電等で扇風機・エアコンが使えない場合、こまめな水分・塩分補給、室内・外出時・衣服の工夫による予防を案内。

## F-B047-002 厚生労働省「エアコンが使用できないときの熱中症対策」
案内ページ: https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/kenkou/nettyuu/nettyuu_taisaku/pamph.html
- 故障・停電時などエアコンが使えないと熱中症リスクが高まるとして専用リーフレットを公開。
- 暑さを避ける、水分補給、体を冷やす等の対策を記事の骨格に使用する。

## F-B047-003 厚生労働省「熱中症が疑われる人を見かけたら」
URL: https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/kenkou/nettyuu/nettyuu_taisaku/happen.html
- 涼しい場所へ移動、衣服をゆるめ体を冷やす、水分補給を案内。
- 自力で水が飲めない、意識がない場合は救急車を呼ぶ。
- 心臓・腎臓等の疾患で水分摂取の指示がある人は医師の指示に従う。

## F-B047-004 厚生労働省「熱中症関連情報」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/nettyuu/index.html
- 2026年の熱中症注意喚起、災害時対策資料を確認。

## 記事内の安全境界
- 自宅に居続けることを目的にせず、冷房のある避難所・公共施設・親族宅等へ移れるなら早めに検討。
- モバイル扇風機は補助であり、危険な高温環境を安全化する保証ではない。
- 発電機・燃焼機器は一酸化炭素中毒リスクがあるため屋内利用を推奨しない。
- 経口補水液・塩分を過剰に取らせる表現を避ける。
