# B045 一次情報メモ

確認日: 2026-09-05

## F-B045-001 厚生労働省「家庭での食中毒予防」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00008.html
- 冷蔵・冷凍が必要な食品は速やかに冷蔵庫・冷凍庫へ入れる。
- 家庭での保存目安として冷蔵庫10℃以下、冷凍庫-15℃以下を案内。
- 肉・魚等の汁による交差汚染を避ける。

## F-B045-002 厚生労働省「計画停電による食品等の温度管理について」
URL: https://www.mhlw.go.jp/topics/bukyoku/iyaku/syoku-anzen/gyousei/dl/110314_01.pdf
- 食品営業施設向け通知だが、停電前後の庫内温度確認と、停電中に庫内温度へ影響する扉の開閉を控える考え方を確認できる。
- 家庭向けの一律安全時間には転用しない。

## F-B045-003 厚生労働省「一般家屋や食品営業施設における浸水後の消毒の相談について」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000122746_00005.html
- 停電により温度が上がってしまった冷蔵庫・冷凍庫内の食品は廃棄するよう食品営業施設へ案内。
- 浸水と停電が重なった場合の安全側の参考として使用する。

## F-B045-004 厚生労働省「家庭でできる食中毒予防の6つのポイント」
URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00006.html
- 温度管理、早めの消費、十分な加熱等の基本原則を確認。

## 使用しない一律基準
- 海外機関が示す停電○時間の基準を、日本の全家庭にそのまま適用しない。
- 冷蔵庫の機種、庫内量、室温、扉開閉、停電前の温度で条件が異なるため。

## 記事内の原則
1. 扉を開ける回数を減らす。
2. 温度管理ができていたかを重視する。
3. 要冷蔵・要冷凍食品で安全性が分からない場合は無理に食べない。
4. 味見で安全確認しない。
5. 復旧後も冷えない・異臭・損傷・浸水があれば機器安全を優先する。
