## 本文視覚要素

実写画像を増やし過ぎず、以下をHTMLで視覚化する。

- `発災直後 → 安全な場所で待機 → 情報確認 → 分散帰宅` の4段階
- `勤務先・学校 / 行き場がない / 帰宅開始後` の行動比較表
- `一時滞在施設 / 一時待機場所 / 災害時帰宅支援ステーション` の役割比較
- 72時間の意味を誤解させない注意ボックス
- 保存用チェックリスト

## 注意

- 人が密集した被災写真を恐怖喚起目的で使わない。交通停止時に「駅へ集中すると混乱する」背景理解の補助に限定する。
- 「駅へ行けば必ず安全」「駅が一時滞在施設」という誤解を生むキャプションにしない。
- Commons画像はproduction buildの既存ローカライズ処理でWebP化し、作者・出典・ライセンス表示を保持する。
