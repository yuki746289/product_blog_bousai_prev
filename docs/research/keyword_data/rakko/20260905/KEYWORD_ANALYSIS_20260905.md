## 5. 月間検索数が取れないことの影響

今回のデータだけで分かるのは、主として**検索意図の存在と広がり**であり、各テーマの絶対需要ではない。

したがって、次のように扱う。

- `停電 冷蔵庫` の271件を「月271検索」と解釈しない。
- 31件の `台風 窓ガラス` が13件の `停電 熱中症` より必ず検索数が多いとは断定しない。
- 0件だった `高潮 避難` や `災害 常用薬` を「誰も検索しない」と判断しない。
- 安全性・制度改定・サイトギャップが大きいテーマは、サジェストが少なくても記事価値がある。

Search Consoleに実データが蓄積した後は、表示回数・クエリ・平均順位を優先して次の制作順を補正する。
