# B042 画像選定記録

確認日: 2026-09-05

## 結論

- image_source_count: 0
- image_status: APPROVED

洪水キキクルの画面やハザードマップを静止画転載すると、2026年の運用変更後もUI・表示内容が更新される可能性があり、読者が古い表示を現在の画面と誤認するリスクがある。

また、特定地域の河川写真は「この水位・この河川なら危険」という誤読を誘発しやすい。

そのためB042は、

- 警戒レベル比較表
- 大河川 / 中小河川の役割分離
- 安全ボックス
- 保存用チェックリスト
- 気象庁・国土交通省への公式リンク

を視覚要素として使用し、汎用被災写真は置かない。

今後、気象庁等から再利用条件が明確で2026年体系を示す恒久的図版が確認できた場合のみ追加を再検討する。
