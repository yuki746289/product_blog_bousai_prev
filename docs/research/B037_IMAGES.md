## 判断理由

浸水後の清掃画像は、被災者・個人宅・私有物が写るケースが多く、文脈や権利の確認を厳密に行う必要がある。

今回の目的は「安全確認 → 記録 → 清掃 → 乾燥 → 必要な消毒」という作業順を誤解なく伝えることであり、無理に被害写真を置くより、HTMLのステップ表示・表・安全ボックスの方が情報伝達上適切と判断した。

## 本文視覚要素

- 5段階フロー: `安全確認 → 記録 → 清掃 → 乾燥 → 必要な消毒`
- 床上 / 床下 / 屋外の違いを示す表
- 清掃時の防護具チェック
- 「消毒から始めない」安全ボックス
- 相談先一覧
- 保存用復旧チェックリスト

## 後日画像を追加する場合

条件:

- 日本の水害復旧・清掃場面
- 被災者の尊厳を損なわない
- 個人宅の識別情報・顔等へ配慮
- 作者・ライセンス・撮影文脈を確認
- 単なる被害の強調ではなく、清掃・乾燥など本文理解に寄与する

条件を満たさないストック画像・海外画像は使用しない。
