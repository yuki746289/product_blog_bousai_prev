# B042 一次情報メモ

確認日: 2026-09-05

## F-B042-001 気象庁「洪水キキクル」

- 洪水キキクルは中小河川等の洪水危険度を5段階で表示。
- 3時間先までの流域雨量指数予測等を用いる。
- 自治体の避難指示やレベル4氾濫危険情報等が出ている場合はキキクルに関わらず避難行動を取る。
- 上流の危険度も確認する。
- 洪水予報河川の外水氾濫は指定河川洪水予報等を確認する。

URL: https://www.jma.go.jp/jma/kishou/know/bosai/riskmap_flood.html

## F-B042-002 気象庁「指定河川洪水予報」

- 指定河川洪水予報は国土交通省または都道府県と気象庁が共同発表。
- 2026年体系ではレベル2氾濫注意報、レベル3氾濫警報、レベル4氾濫危険警報、レベル5氾濫特別警報等を使用。

URL: https://www.jma.go.jp/jma/kishou/know/bosai/flood.html

## F-B042-003 気象庁「新たな防災気象情報について（令和8年〜）」

- 2026年5月29日から新体系開始。
- 河川氾濫・大雨・土砂災害・高潮を5段階の警戒レベルに対応させた。

URL: https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html

## F-B042-004 内閣府「避難情報に関するガイドライン（令和8年3月改定）」

- 警戒レベル4までに危険な場所から避難する考え方。
- 2026年新防災気象情報の名称・活用方法を反映。
- レベル5は安全な立退き避難を待つ段階ではない。

URL: https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/

## F-B042-005 国土交通省「川の防災情報」

- 河川水位・河川カメラ等を遠隔確認するための公式情報源として案内。
- 記事では川へ直接見に行かないための代替手段として扱う。

URL: https://www.river.go.jp/

## 記事で独自数値を置かない項目

- 何mの水位なら個人が避難開始するか
- 浸水深何mなら2階で安全か
- 川から何m離れれば安全か
- 徒歩何分以内なら避難可能か

自治体ハザードマップ・避難情報・河川ごとの情報を優先する。
