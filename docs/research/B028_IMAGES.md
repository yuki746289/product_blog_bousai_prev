# B028 画像・視覚要素メモ

確認日: 2026-09-01

## 方針

B028は特定商品の写真を記事冒頭へ置くと、情報記事より広告記事に見えやすいため、現段階では外部の商品写真をヒーロー画像として採用しない。

本文では以下を主要な視覚要素とする。

- 容量Wh / 定格出力W / 重量の比較表
- 小型・中容量・1kWh級の用途別商品カード
- リチウムイオン電池の安全注意ボックス
- 定期点検チェックリスト

正式なAmazonアソシエイト商品表示を実装する際に、Amazon側の商品画像を商品カード内へ表示する。

## 日本文脈

- 海外住宅・海外停電風景等のイメージ画像は使用しない。
- 日本国内向けメーカー仕様、日本の経済産業省・消費者庁情報を本文の根拠とする。
- AI生成で製品写真に似せた画像は、実在商品の性能・外観を誤認させるため使用しない。

## 安全判断用途

画像・商品カードのみで、使用可能時間、医療機器対応、安全性、リコール有無を判断させない。
