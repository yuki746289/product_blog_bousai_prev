# 台風・大雨クラスタ 優先レビュー 2026-09-04

## 1. 目的

2026年8月後半〜9月上旬に台風・前線・大雨による被害情報が相次いでいる状況を踏まえ、既存の台風・大雨・水害記事群を優先的に再監査し、既存記事強化と新規記事候補を整理する。

## 4. 新専門家基準で見た主な不足候補

### A. 土砂災害に特化した避難判断

**判定: 新規detail/practical候補として優先調査**

B005では土砂災害を水害リスクの一つとして扱っているが、独立記事はない。

一方、気象庁の現行2026年情報では、土砂キキクル、レベル2〜5の土砂災害情報、早めの立退き避難、暴風前の避難等について具体的な行動判断が示されている。

主要論点:
- 土砂災害警戒区域等の確認
- 土砂キキクルの色と行動
- 高齢者等と一般の避難開始タイミング
- 自治体避難情報との併用
- 暴風で移動不能になる前の避難
- 既に移動が危険な場合の緊急安全確保
- 前兆現象を「待つべきサイン」と誤解させない説明

一次情報候補:
- 気象庁「土砂キキクル」
  https://www.jma.go.jp/jma/kishou/know/bosai/doshakeikai.html
- 気象庁「土砂災害に関する防災気象情報の活用」
  https://www.jma.go.jp/jma/kishou/know/ame_chuui/ame_chuui_p8-1.html

仮タイトル例:
- `大雨で土砂災害が心配なとき、いつ避難する？土砂キキクルと避難判断`

### B. 浸水後の家屋清掃・乾燥・感染症対策

**判定: 新規practical候補として優先調査**

B015は「片付ける前の記録」が主役で、清掃・乾燥・消毒の手順は別検索意図である。

厚生労働省は、浸水後はまず土砂撤去・清掃・十分な乾燥を行い、その上で必要に応じて消毒するという順序を案内している。2026年8月の豪雨後にも自治体が同内容を更新している。

主要論点:
- 帰宅・再入室前の安全確認
- 感電、ガス、構造損傷を優先
- PPE（手袋、靴、マスク等）
- 泥・汚れの除去
- 換気・乾燥
- 消毒を先にしない
- 床上・床下等で対応が異なる可能性
- 食品・食器・井戸水等を別判断する
- 自治体の消毒支援・廃棄ルール確認
- B015の被害記録との順序関係

一次情報候補:
- 厚生労働省「一般家屋や食品営業施設における浸水後の消毒の相談について」
  https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000122746_00005.html
- 厚生労働省「被災した家屋での感染症対策」
  https://www.mhlw.go.jp/stf/newpage_00341.html

仮タイトル例:
- `家が浸水した後の片付けは何から？清掃・乾燥・消毒の順番と注意点`

### C. 2026年の新しい大雨・土砂災害情報とキキクル

**判定: 既存記事強化を先に実施。独立記事は需要確認後**

2026年5月29日から防災気象情報が新体系になり、大雨・土砂災害等の情報が警戒レベルとの対応を意識した名称になっている。B005/B006では既に概要を反映している。

ただし、キキクルの種類・色・自治体避難情報との関係を詳しく知る検索意図は別に存在する可能性がある。

### D. 線状降水帯の情報を受け取ったときの行動

**判定: 現時点では単独記事を即作成しない。B005/B006への補足またはQ&A候補**

2026年から線状降水帯の直前予測や新名称が導入されているため現在性は高い。

ただし、「線状降水帯そのものの解説」だけでは気象解説サイトと競合しやすい。自サイトでは、

- 情報を受けたら何を見るか
- キキクル・河川水位・自治体避難情報へどう接続するか
- 危険な場所にいる場合どう動くか

という行動判断に寄せる場合のみ独立価値がある。

一次情報候補:
- 気象庁「線状降水帯に関する情報」
  https://www.jma.go.jp/jma/kishou/know/bosai/kishojoho_senjoukousuitai.html
