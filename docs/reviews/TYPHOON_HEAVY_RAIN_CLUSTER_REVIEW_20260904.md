## 2. 第1次結論

### 結論A: 既存クラスタは事前準備が厚い

B005/B006/B012/B020/B021は、

- ハザードマップ
- 避難先・経路
- 自宅の浸水リスク
- 屋外作業の打ち切り
- 停電・断水
- 車の移動
- 家族が不在の場合
- 高齢者・乳幼児等の前倒し

を既にかなり具体的に扱っている。

したがって、「台風対策まとめ」「大雨前にやること」等の類似記事を追加するとカニバリ・重複が起こりやすい。新規記事は既存記事で答えていない独立意図に限定する。

### 結論B: 土砂災害は独立記事の余地が大きい

B005/B012では土砂災害を水害リスクの一つとして触れているが、

- 土砂災害警戒区域等
- 土砂キキクル
- レベル2〜5情報
- 高齢者等と一般の避難タイミング
- 暴風前の立退き
- 既に屋外移動が危険な場合

をまとめた独立ページはない。

E02（防災安全）、E04（情報設計）、E06（読者行動）、E13（日本向け制度文脈）の観点から、独立記事候補として妥当。

### 結論C: 浸水後の復旧・衛生は独立記事の余地が大きい

B015のpage jobは「片付け前に写真・証拠を残すこと」であり、清掃・乾燥・消毒とは役割が異なる。

厚生労働省は、浸水後の感染症対策として清掃・乾燥を先に行い、必要に応じてその後に消毒する考え方を示している。

よって、

- B015: 記録
- 新規候補: 安全確認→清掃→乾燥→必要な消毒

と分離できる。

### 結論D: 2026年防災気象情報は既存強化を優先

B005/B006には2026年5月29日の新体系を既に反映している。

独立記事をすぐ作るより先に、

- 現在の正式名称
- キキクルへの導線
- 自治体避難情報との関係
- 色と行動の表現

を2026-09-04時点の気象庁情報で再確認する。

独立記事化は検索意図・需要が十分に分離できる場合だけとする。

## 4. 記事候補の暫定順位

### A1 土砂災害

仮検索意図:
- 大雨のとき土砂災害はいつ避難するか
- 土砂キキクルをどう見ればよいか
- 崖の近くでは何を基準に動くか

仮page job:
危険区域にいる一般生活者が、警戒情報・キキクル・自治体避難情報を組み合わせて、遅れずに避難開始を判断できるようにする。

### A2 浸水後の清掃・乾燥・消毒

仮検索意図:
- 家が浸水した後、何から片付けるか
- 消毒はいつ行うか
- 泥水が入った家の感染症対策

仮page job:
被災後の家庭が、安全確認を優先しながら、記録後に清掃・乾燥・必要な消毒へ進む順序を理解できるようにする。

## 5. 現段階で作らない記事

### 個別台風のニュース記事

例:
- 台風24号まとめ
- 2026年9月大雨の被害速報

理由:
- 鮮度寿命が短い
- 公的・報道機関と速報競争になる
- サイトの強みである恒常的な行動支援と合いにくい
- 更新停止時に古い災害情報が残るリスクがある

現在の災害は、恒常記事の優先度を上げるトリガーとして扱う。
