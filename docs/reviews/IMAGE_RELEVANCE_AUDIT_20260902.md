# 画像関連性レビュー 2026-09-02

## 目的

推奨画像数を満たすこと自体を目的にせず、各画像が配置章の理解を直接補助しているかを優先して再レビューする。

## 判定原則

- 推奨画像数は目安であり、関連性の低い画像を入れてまで達成しない。
- 各画像について「どの章の何を補助するか」を説明できることを採用条件とする。
- 「防災らしい」「災害写真である」というだけの画像は採用しない。
- 適切な実画像が弱い場合は、安全な記事専用AI画像を検討する。
- AI画像も記事理解へ寄与しない場合は、画像なしを選ぶ。
- 表・カード・チェックリスト・注意枠等の見せ方は、画像数にかかわらず原則実施する。

## AI画像の追加候補

AI画像は枚数合わせではなく、以下のように実画像では表現しにくい「行動」を説明する場合のみ検討する。

### 優先度 高

- **B014**: 家財一覧と火災保険・家財保険の書類を確認する家庭
- **B015**: 浸水後、安全を確認したうえで家財や型番を撮影・記録する場面
- **B017**: 地震保険証券と火災保険証券を並べて契約内容を確認する場面
- **B020**: 大雨前に1階の家財を高い場所へ移す、備蓄品をまとめる等の事前準備

### 優先度 中

- **B013**: ハザードマップと保険証券を並べて水災補償を確認する場面
- **B029**: 車載防災用品を用途別に整理する一般的な場面。ただし実在商品の外観・性能は再現しない

## AI画像の安全条件

- イメージ画像であることを必要に応じて明記する。
- ハザードマップ、避難経路、安全水深、補償可否、損害区分、商品性能の根拠には使用しない。
- 実災害写真の代替として使わない。
- 実在商品の正確な外観を再現しない。
- 記事ごとの専用画像とし、安易に使い回さない。
