## 1. 目的

一般情報記事の中で、読者が商品を必要とする理由・用途・選び方を理解した直後に、対応する商品紹介記事へ自然に進めるかを B001〜B030 で横断確認する。

確認方針:

- 商品リンクを記事末尾だけに依存しない
- 商品説明・備蓄説明・用途説明の直後を優先する
- 一般情報記事から Amazon へ直接大量誘導しない
- 商品との関連が弱い記事へ無理に導線を追加しない
- 高リスク記事では安全情報を商品導線より優先する
- 同じリンクを短い間隔で過剰に繰り返さない
- Markdown / preview HTML / 記事別チェックリストの整合を確認する

## 4. 今回修正した不整合

### B006

Markdownでは本文中の4商品カテゴリ導線の直後に、同じ4リンクを「関連する商品紹介」として再掲していた。一方、preview HTMLではすでに重複ブロックが削除されていた。

対応:

- Markdown側の重複4リンクを削除
- preview HTMLの現状を正として同期
- 記事別チェックリストの「旧まとめ4リンクを削除」と整合

### B008 / B009 / B010

- 高リスク記事で購買導線が安全情報より前に出ていない: PASS

対応:

- 古いTODO行を削除

### B022

本文とpreview HTMLではすでに文脈内の商品導線が実装済みで、後段の再レビューでもPASSだったが、旧セクション5にTODOが残っていた。

対応:

- 「関連商品がある場合、商品紹介ページ導線を検討した」をPASSへ同期
- 「高リスク記事で購買導線が安全情報より前に出ていない」をPASSへ同期

## 5. 結論

今回の横断監査では、**新たな商品リンクを追加するより、既存の文脈導線を維持し、重複や古いチェック状態を整理する方が適切**と判断した。

特に、保険・被災後手続き・家族連絡・安全判断が主題の記事へ商品導線を増やすと、読者誘導が広告目的に見えやすくなるため追加しない。

現在の基本導線は、

**情報記事 → 必要性・用途の理解 → 商品紹介記事 → Amazon**

の順を維持する。
