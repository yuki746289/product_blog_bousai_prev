# 記事本文 → Q&A 文脈導線 横断監査

作成日: 2026-09-02

## 1. 方針

記事末尾へ一律にQ&Aリンクを追加するのではなく、本文中に既存Q&Aと直接対応する疑問がある場合だけ、説明章の末尾から個別質問へ接続する。

基本形:

```text
記事本文で疑問・判断条件を説明
  ↓
Q&A：具体的な質問
  ↓
qa.html#qa-...
```

Q&Aは本文説明の代替にしない。

## 3. Q&AリンクUI

- 「Q」の丸アイコン

## 4. 個別アンカーの動作

Q&AページでURL hashを検出し、対象が `details.qa-item` なら自動で開く。

これにより記事から個別Q&Aへ移動した際、質問を再度クリックせず回答を確認できる。
