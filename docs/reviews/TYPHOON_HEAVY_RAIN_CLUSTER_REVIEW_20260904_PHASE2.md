## 3. B005 / B006 の2026年防災気象情報照合

### 確認した一次情報

- 気象庁「新たな防災気象情報について(令和８年～)」
  - https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/
- 気象庁「土砂キキクル」
  - https://www.jma.go.jp/jma/kishou/know/bosai/doshakeikai.html
- 気象庁「キキクル」
  - https://www.jma.go.jp/jma/kishou/know/bosai/riskmap.html

### 事実確認

- 2026年5月29日から新たな防災気象情報の運用が開始された → 正しい
- 従来の大雨警報は「レベル３大雨警報」という名称に変更 → 正しい
- 自治体の警戒レベル3高齢者等避難、警戒レベル4避難指示が出た場合は速やかに行動 → 正しい
- 自治体の避難情報が未発令でも、警戒レベル3・4相当の防災気象情報が出た場合はキキクル等を用いて自ら判断する → 正しい
- 土砂分野では、レベル2土砂災害注意報、レベル3土砂災害警報、レベル4土砂災害危険警報、レベル5土砂災害特別警報を使用 → 現行名称として確認
- 土砂キキクルは、黄=注意、赤=警戒、紫=危険、黒=災害切迫 → 現行運用として確認
- 土砂災害警戒区域等では、高齢者等は遅くとも赤、一般の人は遅くとも紫で避難開始が重要 → 気象庁の現行説明と一致

### B005 / B006判定

**重大な事実誤りは確認されなかった。**

現行記事は「2026年5月29日に体系変更」「レベル3・4相当情報でも自ら判断」という一般向け表現に留めており、安全側である。

ただし、独立した土砂災害記事を追加する場合は、B005/B006で土砂系の新正式名称を細かく展開せず、B036候補へ分岐させる方が情報設計上よい。

## 4. B008 車の冠水・水没

### 判定: PASS

確認先:

- 国土交通省「水深が床面を超えたら、もう危険！」
  - https://www.mlit.go.jp/jidosha/carinf/rcl/carsafety_sub/carsafety033.html
- 国土交通省「豪雨に備えて、車に脱出用ハンマーを備えましょう！」
  - https://www.mlit.go.jp/jidosha/carinf/rcl/carsafety_sub/carsafety040.html
- JAF 水没テスト
  - https://jaf.or.jp/common/safety-drive/car-learning/user-test/disaster/submerge-test

所見:

- 「冠水路へ入らない」を最上位行動としている点は妥当
- 床面以下を安全基準にしない説明は妥当
- 窓・ドア・脱出用ハンマーの順序は公的説明と概ね整合
- 合わせガラスの注意を明記しており良い
- 水が引いた後に自走確認しない方針も安全側

新規類似記事は不要。

## 5. B009 冠水道路

### 判定: PASS

確認先:

- JAF 2025年のBEV/HV/ガソリン車冠水路走行テスト
  - https://jaf.or.jp/common/safety-drive/car-learning/user-test/disaster/flood-driving
- JAF 冠水路走行テスト
  - https://jaf.or.jp/common/safety-drive/car-learning/user-test/disaster/waterway-driving

所見:

- 一律の走行可能水深を設定しない方針は妥当
- 前車・SUV・低速走行等を安全根拠にしない構成は良い
- JAFテストを「走行可否の基準」にしない注意も適切
- B008との役割分担も明確

新規類似記事は不要。

## 6. B010 地下駐車場

### 判定: PASS

確認先:

- 国土交通省「国管理の地下駐車場に関する浸水対策ガイドライン（直轄地下駐車場）」2026年3月
  - https://www.mlit.go.jp/road/road/traffic/sesaku/ope_mente_guideline.html

記事中の「2026年3月に国交省がガイドラインを策定」「浸水リスクの早期把握・早期判断を重視」は一次情報と一致する。

所見:

- 個人向け安全基準としてガイドラインを誤用していない
- 車両保全より避難・安全を優先
- 管理主体、止水設備、機械式駐車場等を分けて説明

新規類似記事は不要。
