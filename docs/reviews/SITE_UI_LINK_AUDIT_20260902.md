# サイトUI役割・旧準備中リンク横断監査

作成日: 2026-09-02  
対象: `preview/` の記事・カテゴリ・商品紹介・トップ・Q&A

## 1. 監査目的

ユーザー指摘を受け、以下を全体確認した。

1. 章見出しと商品紹介記事へのCTAが同じ色・同じ役割に見えていないか
2. 作成済み記事に対して「準備中」表示が残っていないか
3. 作成済み記事へのリンクが `href="#"` のまま残っていないか
4. `title-link--planned` 等の旧planned状態が残っていないか
5. 同一商品記事へのCTAが短い間隔で過剰重複していないか

## 2. CSS役割分離

共通CSS `preview/bousai_common.css` を、意味ベースのsemantic roleで分離した。

| 役割 | 主なCSSトークン | 色系統 |
|---|---|---|
| 章見出し | `--role-section-*` | 緑 |
| 要点・結論 | `--role-summary-*` | 青緑 |
| 注意 | `--warning-*` | 橙 |
| 危険・禁止 | `--danger-*` | 赤 |
| 出典・公的情報 | `--info-*` | 青 |
| 商品紹介記事への内部CTA | `--role-product-*` | 紫 |
| Amazon等の購入CTA | `--role-purchase-*` | 濃い青 |
| 関連記事 | `--role-related-*` | ニュートラル |
| 表ヘッダー | `--role-table-*` | 青灰 |

重要ルール:

- 商品紹介記事へのCTAは章見出しと同じ背景色・アクセント色を使わない
- Amazon購入ボタンとサイト内の商品比較CTAを同じ見た目にしない
- 注意・危険の色を販促CTAへ流用しない
- 記事固有の直書き色ではなく、共通CSSの意味ベース変数を使用する

## 6. 残る `href="#"` について

記事リンクとは別に、旧プレビューの一部ページではフッターに次のリンクが `href="#"` のまま残っている。

- 運営方針
- 免責事項
- プライバシーポリシー
- 広告について
- お問い合わせ

これらは**作成済み記事への旧準備中リンクではなく、遷移先ページ自体が未作成の別課題**である。

今回、存在しないページへ仮URLを付けることはせず、別の本番化タスクとして残す。
