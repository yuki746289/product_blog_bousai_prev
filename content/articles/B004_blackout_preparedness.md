# 停電に備えて準備しておきたいもの｜照明・電源・情報収集を分けて考える

停電対策は「大容量の電源を買うこと」から始める必要はありません。まず**照明・情報・連絡・充電・生活維持**に分け、停電中に何を使い続けたいかを整理します。

## 結論

停電への備えは、最初に**暗闇をなくす、情報を取る、連絡手段を残す**の3点を確保し、その後に冷蔵・調理・暑さ寒さなど家庭固有の課題を考えると整理しやすくなります。地震時は停電復旧後の電気火災にも注意します。

## 停電対策を5つの役割に分ける

- **照明**：懐中電灯、ランタン、足元灯。
- **情報**：ラジオ、スマートフォン、自治体情報。
- **連絡**：スマートフォン、家族の連絡先メモ。
- **充電**：モバイルバッテリー、予備電池、必要に応じて外部電源。
- **生活維持**：水、食品、トイレ、季節対策、医療機器等。

「電源容量が何Wh必要か」を先に考えるより、**停電時も動かしたい機器を列挙する**方が、過不足を把握しやすくなります。

## 照明は1本ではなく、場所と用途を分ける

**停電直後**は転倒物やガラスが見えにくくなります。枕元、玄関、廊下など、暗闇でも手を伸ばせる位置にライトを置きます。スマートフォンのライトだけに頼ると、通信・連絡に必要な電池を消費します。

- 移動用：懐中電灯・ヘッドライト
- 部屋用：ランタン型ライト
- 夜間の足元：自動点灯型や蓄光表示
- 予備：乾電池・充電池を製品仕様に合わせて用意

→ [停電用ライト・ラジオの商品を比較する](/goods/light-information.html)

> **裸火を照明代わりにしない**
>
> 余震や転倒物がある状況で、ろうそく等の裸火を常用するのは火災リスクがあります。電池式照明を基本に考えます。

## 情報はスマートフォン一択にしない

スマートフォンは重要ですが、基地局障害、通信混雑、充電切れが重なる可能性があります。自治体の防災情報、テレビ・ラジオ、家族の連絡ルールなど、**複数の情報経路**を用意します。

停電時にWi-Fiルーターが止まれば、自宅の固定回線経由の通信も使えない場合があります。どの機器が停電で止まるのか、平常時に確認しておくと判断しやすくなります。

## 充電は「何を何回動かすか」で考える

| 対象 | まず確認すること | 備えの例 |
| --- | --- | --- |
| スマートフォン | 1日何回充電するか | モバイルバッテリー |
| ライト | 電池種類・連続点灯時間 | 予備電池 |
| ラジオ | 乾電池か充電式か | 予備電池・USB電源 |
| 医療・生活機器 | 停止できる時間があるか | メーカー・医療機関と非常電源を確認 |

ポータブル電源は家庭によって有用ですが、必須とは限りません。具体的な容量比較は商品記事で扱い、情報記事では**必要な負荷と使用時間の整理**を優先します。

→ [モバイルバッテリー・ポータブル電源を比較する](/goods/power-charging.html)

## 地震による停電では復電後の火災にも備える

内閣府は、地震後の電気火災対策として感震ブレーカー等の普及を進めています。避難時にブレーカーを操作できない場合にも自動遮断が役立つ一方、急に電気が止まることを前提に照明等を準備する必要があります。

- 感震ブレーカーの種類と自宅設備への適合を確認
- 停電時に自動点灯する照明を検討
- 復電前にガス漏れや家電の損傷を確認
- 焦げ臭い場合は使用を止め、原因不明なら専門家へ相談

感震ブレーカーだけで地震火災が完全に防げるわけではありません。家具固定、耐震化、火気管理と組み合わせます。

## 冷蔵庫・調理・暑さ寒さは家庭差が大きい

冷蔵庫をどこまで維持するか、電気調理器具しかないか、乳幼児や高齢者がいるかなどで必要な備えは変わります。停電が長引く前提なら、冷蔵が必要な食品から消費するなど、**電気を使わない生活手順**も決めます。

夏季・冬季は室温管理が安全に直結する場合があります。長時間の停電で自宅環境を保てない場合は、自治体の開設施設や安全な場所への移動も選択肢にします。

## 停電と同時に断水・物流停止も考える

大規模災害では電気だけでなく、水道、ガス、通信、店舗の営業、物流が同時に影響を受けることがあります。最低3日分、できれば1週間分の飲料水・食品等を備えるという国の案内を、停電対策にも組み込みます。

- 飲料水・食品
- 携帯トイレ
- 衛生用品
- 常用薬・個別用品

→ [水・非常食と携帯トイレの具体例を見る](/goods/water-food.html) / [携帯トイレ・衛生用品を比較する](/goods/toilet-hygiene.html)
- 現金・連絡先
- カセットコンロ等を使う場合は換気・火気安全を守る

## 停電前に10分で確認するチェック

| 確認 | できている？ |
| --- | --- |
| 枕元のライト | □ |
| 予備電池 | □ |
| スマホとモバイルバッテリーの充電 | □ |
| ラジオ等の別情報手段 | □ |
| 水・食品・トイレ | □ |
| 家族の連絡方法 | □ |
| 医療・生活機器の非常時対応 | □ |

大きな機器を買う前に、このチェックで不足を洗い出すと、家庭に必要な停電対策が見えやすくなります。

## まとめ：まず小さな電源から守る

最優先は、照明、情報、連絡を維持することです。そのうえで家庭固有の機器を整理し、大容量電源が本当に必要かを判断します。**「停電したら何が止まるか」を一度家の中で想像すること**が、最も実用的な準備になります。

## 冷蔵庫は「停電した瞬間」より、その後の使い方を決める

停電すると冷蔵庫・冷凍庫は徐々に温度が上がります。停電直後から何度も扉を開けると冷気が逃げやすくなるため、必要な物を取り出す回数を減らす工夫が必要です。停電の長さや室温によって食品の状態は変わるため、**見た目や時間だけで安全を断定しない**ようにします。

停電前に保冷剤を凍らせておく、冷蔵庫内を整理しておく、常温で食べられる食品を別に備えておくと、停電時に冷蔵庫へ依存しすぎずに済みます。長時間停電が続き、食品の安全に不安がある場合は無理に食べない判断も必要です。

## 医療機器・介護用品は一般家庭より早く個別確認する

在宅酸素、吸引器、電動ベッド、人工呼吸器など、電気停止が健康に直結する機器がある家庭では、一般的な「モバイルバッテリーを何台用意するか」という考え方だけでは不十分です。

機器の消費電力、内蔵バッテリーの稼働時間、外部電源の対応可否、停電時の連絡先を、**医療機関・機器メーカー・訪問看護等と平常時に確認**します。家庭用蓄電池やポータブル電源が使えるかどうかも、電圧・波形・接地等の条件があるため自己判断しません。

また、エレベーターが止まる集合住宅では、外出・避難・物資運搬の負担が増えます。高層階ほど、水や食料を停電後に運び上げるのが難しくなるため、在宅備蓄の優先度が高くなります。

## 自宅の停電と地域停電を分けて確認する

照明が消えたとき、まず周囲の住宅や共用部も消えているか確認します。自宅だけならブレーカーや漏電遮断器が作動している可能性がありますが、**原因が分からないまま何度もブレーカーを入れ直さない**ようにします。

浸水、焦げ臭さ、火花、配線損傷などがある場合は通電を試さず、電力会社や電気工事事業者等へ相談します。地域全体の停電であれば、電力会社の停電情報や自治体情報を確認し、復旧見込みが長い場合は生活維持策へ切り替えます。

## 停電訓練を短時間だけやってみる

平常時に30分程度、主照明を使わずに過ごしてみると、ライトの置き場所、スマートフォンの充電残量、トイレまでの動線など、一覧表だけでは気づきにくい不足が見えます。冷蔵庫や医療機器など止めてはいけない設備は対象外にし、**安全な範囲の模擬停電**として行います。

## 充電ケーブルも「使える組み合わせ」で保管する

予備電源があっても、端子の違うケーブルしかなければ使えません。USB-C、Lightning等、家族の機器ごとに必要なケーブルを確認し、**電源本体と一緒に保管**します。災害時だけ使うケーブルも、定期的に断線や充電可否を確認します。
