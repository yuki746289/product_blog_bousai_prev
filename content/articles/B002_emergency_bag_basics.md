# 防災リュックの中身は何を入れる？最低限の持ち出し品と重さ・置き場所

防災バッグを準備しようとすると、「とにかく全部入れた方が安心」と考えがちです。しかし、避難時に持ち出すバッグは、自宅で数日過ごすための備蓄とは役割が違います。

内閣府は、急いで自宅から避難する場合に備え、**「すぐに必要になるもの」「ないと困るもの」**を非常持ち出し品として事前にリュック等へ入れておくことを案内しています。消防庁も、最小限の非常持ち出し品を普段から用意し、すぐ取り出せる場所に置くことを勧めています。

この記事では、「防災バッグに何を入れるか」を単純な商品リストではなく、用途別に整理します。

## 結論：防災バッグは「持って避難できる最小限」を優先する

防災バッグを考える時は、次の順で整理すると分かりやすくなります。

1. 自宅備蓄と持ち出し品を分ける
2. 避難直後に必要なものから入れる
3. 自分・家族に代わりがきかないものを優先する
4. 重くしすぎない
5. すぐ持ち出せる場所に置く
6. 定期的に中身を見直す

「防災用品を全部入れたバッグ」ではなく、**「避難する時に実際に持てるバッグ」**にすることが重要です。

## 1. まず自宅備蓄と防災バッグを分ける

自宅で数日生活するための備蓄と、避難時に持ち出すものでは目的が違います。

| 分類 | 主な目的 | 例 |
|---|---|---|
| 自宅備蓄 | 在宅避難やライフライン停止に備える | 水、食料、携帯トイレ、生活用品など |
| 防災バッグ | 避難時に必要なものを持って移動する | 飲料水、非常食、ライト、常備薬、衛生用品など |
| 日常携行 | 外出中の災害に備える | モバイルバッテリー、ライト、連絡先、身分証明等 |

内閣府の家庭向け案内でも、備蓄と持ち出し品は別に説明されています。

## 2. 防災バッグに入れるものを5つの用途に分ける

### A. 水分・食料

避難直後に必要になる分を中心に考えます。

- 飲料水
- すぐ食べられる非常食・栄養補助食品
- 食べ慣れた小型食品

自宅備蓄の数日分すべてをリュックに入れる必要はありません。**重量とのバランス**を見ます。

→ [水・非常食の選び方と商品紹介](/goods/water-food.html)

### B. 明かり・情報・連絡

- 懐中電灯・ヘッドライト
- 携帯ラジオ
- 予備電池
- スマートフォン
- モバイルバッテリー
- 家族の連絡先を書いたメモ

停電や通信障害を想定し、スマートフォンだけに依存しない準備も検討します。

→ [防災用ライト・ラジオの商品紹介](/goods/light-information.html)  
→ [モバイルバッテリー・電源の商品紹介](/goods/power-charging.html)

### C. 衛生・生活用品

- マスク
- ウェットティッシュ
- タオル
- ティッシュ
- 携帯トイレ
- 生理用品
- 下着など必要最小限の衣類
- 雨具

季節や避難環境によって優先順位は変わります。

→ [携帯トイレ・衛生用品の商品紹介](/goods/toilet-hygiene.html)

### D. 健康・応急用品

- 日常的に必要な薬
- お薬手帳や薬の情報
- 救急用品
- 眼鏡等、生活上欠かせないもの

薬の必要量や保管方法は薬ごとに異なるため、自己判断で長期備蓄するのではなく、**医師・薬剤師等へ確認**します。

### E. 身元確認・お金

- 身分証明書
- 現金
- 必要な連絡先
- 保険・口座等の情報を控えたもの

原本・コピー・デジタル保存の扱いは、紛失・盗難にも注意して家庭ごとに決めます。

## 3. 「人によって必要なものが違う」を最優先にする

消防庁は、非常持ち出し品は**人によって異なる**と案内しています。

例えば、次のように家庭・本人の条件ごとに追加品を確認します。

| 家庭・本人の条件 | 追加で確認したいもの |
|---|---|
| 乳幼児がいる | ミルク、哺乳瓶、紙おむつ等 |
| 高齢者・介助が必要 | 普段使う補助用品 |
| 持病がある | 常用薬、薬の情報 |
| 眼鏡・補聴器等が必要 | 代替しにくい用品 |
| ペットがいる | ペット用の避難用品 |

一般的なチェックリストを埋めるより、**「自分や家族がこれを失うと困る」もの**から考えます。

## 4. 重くしすぎない

持ち出し品は、実際に持って歩けなければ意味がありません。

政府広報オンラインでは、非常持ち出し袋の量の想定として、**成年男性約15kg、成年女性約10kg、子ども・高齢者約6kg**という目安を紹介しています。

ただし、これは個人の体力、年齢、健康状態、移動距離、階段の有無などで大きく変わります。**「この重さまでなら安全」という上限ではありません。**

実際には、数字だけで判断せずバッグを背負って確認します。

- バッグを背負って数分歩けるか
- 階段を上り下りできるか
- 両手を使える状態にできるか
- 家族の荷物を誰が持つか

目安重量より軽くても、体力や移動環境によって負担になることがあります。


## 重すぎたら「避難中に使うか」で減らす

「いらない物」を全国共通の固定リストにするのではなく、**避難途中〜避難直後に使うか**で分けると減らしやすくなります。

1. **自宅で使う物は自宅備蓄へ戻す**  
   数日分の水・食品、かさばる生活用品など、避難中に全部持つ必要がない物は自宅備蓄と分けます。
2. **同じ役割の物が重複していないか確認する**  
   ライト、充電手段、衛生用品などは、似た用途の物を必要以上に重ねていないか見直します。
3. **家族で分散できる物は分ける**  
   全員分を1人のバッグへ集中させず、各自が安全に持てる範囲で分担します。
4. **代替しにくい物は最後まで残す**  
   常用薬、眼鏡、補聴器、乳幼児用品など、本人にとって代わりがききにくい物を先に削らないようにします。
5. **もう一度背負って歩く**  
   平地だけでなく、可能なら階段や玄関までの経路でも確認します。

**「防災用品だから入れる」のではなく、「このバッグを持って避難する場面で使うか」**を基準にすると、必要品を残しながら軽くできます。

容量から見直したい場合は、[防災リュックは何L必要？](article_b032.html)で中身・重さから決める手順を整理しています。

## 5. リュック型を基本に考える

内閣府や消防庁では、非常持ち出し品をリュック等へ入れて準備する例が示されています。

リュック型なら**両手を使いやすい**ため、移動時の自由度を確保しやすくなります。

選ぶ時は、

- 自分の体格に合う
- 肩紐が調整できる
- 開閉しやすい
- 雨への対策を考えられる
- 中身を分類しやすい

といった使い勝手も確認します。

**高価な「防災専用バッグ」でなければならないわけではありません。**普段使っていないリュックを活用する方法もあります。

[20L・30Lなど、防災リュックの容量をどう決めるか](article_b032.html)は別記事で詳しく整理します。

## 6. 置き場所は「すぐ持ち出せるか」で決める

消防庁は、非常持ち出し品を**目につきやすく、すぐ取り出せる場所**へ置くことを案内しています。

政府広報オンラインでは、玄関の近く、寝室、車の中、物置などへ配置する考え方も紹介しています。

ただし、すべてを1か所へ置くか、複数へ分けるかは住宅環境によって変わります。

| 置き場所を決める時 | 複数配置を考える場合 |
|---|---|
| 玄関から持ち出せるか | 寝室 |
| 夜間でも手に取れるか | 玄関付近 |
| 出口をふさがないか | 車内 |
| 家族が場所を知っているか | 物置など |

玄関が使えない場合、夜間、2階からの避難、外出中の被災なども想定して、置き場所を決めます。

## 7. 防災バッグの中身は定期的に見直す

**一度作って終わりではありません。**

見直し項目は「期限・状態」と「暮らしの変化」に分けると確認しやすくなります。

| 期限・状態 | 暮らしの変化 |
|---|---|
| 食品・飲料の期限 | 子どもの成長に伴うサイズ変更 |
| 電池・モバイルバッテリーの状態 | 季節用品 |
| 薬や衛生用品 | 住所・連絡先等の情報 |
|  | 家族構成の変化 |

**半年に1回など、自分が忘れにくい時期**を決めて確認すると管理しやすくなります。

## 最初に作るなら、この簡易チェックから

まずは次の項目をリュックへ入れ、実際に背負ってみます。

- 飲料水
- すぐ食べられる食品
- ライト
- 予備電源
- 携帯ラジオ等の情報手段
- タオル・マスク・衛生用品
- 携帯トイレ
- 日常的に必要な薬・医療情報
- 家族の連絡先
- 身分証明・現金等の必要品

そのうえで、自分・家族に必要な物を追加し、**重すぎるものは自宅備蓄へ戻します。**

## 防災セットを購入する場合も中身を確認する

市販の防災セットは、最初の準備を簡単にできる利点があります。

一方で、

- 家族構成に合っているか
- 自分に必要な薬・衛生用品が含まれているか
- ライトや電源の仕様が合っているか
- バッグが自分で持てる重さか
- 不要な物が多くないか

は個別に確認する必要があります。

**「セットを買ったから準備完了」ではありません。**購入後に中身を入れ替える前提で考えると使いやすくなります。

## まとめ

防災バッグは、できるだけ多くの物を詰め込むことが目的ではありません。

避難する時に、

- すぐ必要になるもの
- ないと困るもの
- 家族にとって代わりがきかないもの

を優先し、**実際に持って移動できる量**にします。

自宅備蓄とは分けて考え、置き場所と定期点検まで決めておくことで、実際に使える防災バッグになります。
