# 水害・台風・地震で保険の扱いはどう違う？

災害時の保険は「台風なら火災保険」「水没なら車両保険」と単純には決まりません。**何が原因で、何が壊れ、どの保険を契約しているか**の3点に分けると整理しやすくなります。

## 結論

住宅では風災・水災を火災保険、地震・噴火・津波を地震保険で確認し、車は自動車保険を別に確認します。**同じ台風でも強風と洪水では補償項目が違い、同じ水没でも洪水と津波では扱いが変わります。**

## 最初に「災害名」ではなく原因を見る

台風という一つの災害でも、強風で屋根が壊れる、水が流入して床上浸水する、車が冠水するといった複数の損害が起こります。

保険では、**風・水・地震・津波など損害の原因**を分けて契約内容を確認します。

## 住宅の基本マトリクス

| 損害例 | 主に確認する保険 |
| --- | --- |
| 強風で屋根・窓が破損 | 火災保険の風災 |
| 洪水・内水・高潮で住宅浸水 | 火災保険の水災 |
| 地震で住宅が損壊 | 地震保険 |
| 地震による火災 | 地震保険 |
| 津波で住宅が流失 | 地震保険 |

## 建物と家財を必ず分ける

火災保険・地震保険では、**建物と家財を別々に契約します**。建物が補償対象でも、家具・家電が同じ契約で補償されるとは限りません。

賃貸住宅では、自分の家財契約と、所有者側の建物契約を分けて考えます。

## 車は住宅保険と別に考える

| 車の損害原因 | 主に確認 |
| --- | --- |
| 台風・洪水・高潮 | 自動車保険の車両保険 |
| 地震・噴火・津波 | 通常の車両保険では一般に対象外、地震等特約の有無 |
| 住宅の地震保険 | 車は家財に含まれない |

## 火災保険に入っていれば自然災害全部ではない

火災保険の商品・契約タイプによって、風災・水災等の補償を外している場合があります。**契約名称だけで判断せず、補償一覧を見ます。**

特に水災は地域リスクを理由に外している契約もあるため、ハザードマップと契約内容を並べて確認します。

## 地震保険は生活再建の位置づけが強い

**地震保険の保険金額は火災保険の30〜50％の範囲**で、限度額もあります。住宅再建費を全額補う仕組みとは異なります。

手元資金、公的支援、住宅ローン等と合わせて、被災後の生活資金を考えます。

## 免責・自己負担・限度額を見る

補償項目が付いていても、免責金額、支払条件、保険金額・限度額等によって受け取れる金額は変わります。

「補償あり/なし」だけでなく、**いくらまで・どの条件で**を確認します。

## 災害前の保険棚卸し

1. **証券を集める**：火災・地震・自動車を一覧化。
2. **対象を確認**：建物・家財・車。
3. **原因別に見る**：風災・水災・地震等。
4. **条件を見る**：免責・限度額・特約。
5. **連絡先共有**：家族が契約先を分かるようにする。

## 被害後は安全→記録→連絡

**保険手続きより先に安全を確保します。**危険な屋根、冠水路、浸水車へ撮影のため近づきません。

安全な範囲で全景・損傷部・浸水高さ等を記録し、保険会社・代理店へ事故連絡します。

## 修理業者の「保険で無料」に注意

自然災害後には、保険金利用を前提とした住宅修理サービスのトラブルが注意喚起されています。保険金支払額は保険会社の確認で決まるため、先に高額契約を結ばないようにします。

**保険会社への相談と修理契約を分けて進める**ことが重要です。

## 公的支援も別の入口で確認

罹災証明、被災者支援、税・融資等は保険とは別制度です。保険に入っているから公的支援が不要、または公的支援があるから保険請求できない、と決めつけません。

**自治体窓口と保険会社の双方を確認**し、利用できる制度を整理します。

## 年1回の確認表

| 契約 | 確認 |
| --- | --- |
| 火災保険 | 風災・水災・建物・家財 |
| 地震保険 | 建物・家財・保険金額 |
| 自動車保険 | 車両保険・地震等特約 |
| 共通 | 免責・連絡先・証券保管場所 |

更新時だけでなく、引っ越し、車の買い替え、住宅改修、家族構成の変化でも見直します。
