# ペットの防災は何を準備する？同行避難・備蓄・持ち出し品を整理

ペットがいる家庭では、人の水・食料・防災リュックだけでは準備が完了しません。**ペット用の水・フード・薬・排泄用品に加え、避難所の受入条件、キャリーやケージへの慣れ、一時預け先**まで平常時に確認します。

環境省は、飼い主自身と家族の安全確保を最優先にしたうえで、ペットの水・食料・常備薬、避難所・避難ルート、基本的なしつけ、キャリーやケージへの慣れなどを事前に準備するよう案内しています。

## 結論：用品だけでなく「避難先・移動・生活」まで準備する

最低限、次の5つに分けて確認します。

1. **命・健康**：フード、水、常備薬、療法食
2. **移動**：キャリー、ケージ、首輪、リード
3. **排泄・衛生**：ペットシーツ、猫砂、排泄物処理用品
4. **情報**：写真、飼い主連絡先、健康情報、かかりつけ動物病院
5. **避難先**：同行避難の可否、避難所ルール、一時預け先

「ペット用品を箱に入れた」で終わらず、**実際に連れて避難できるか**まで確認することが重要です。

## 同行避難は「避難所で一緒の部屋に入れる」という意味ではない

環境省は、避難するときにペットと一緒に避難する「同行避難」を想定し、地域の指定避難場所が同行避難に対応しているか、注意事項を自治体へ確認するよう案内しています。

ただし、避難所でのペットの飼養場所やルールは自治体・施設によって異なります。**同行避難できることと、人とペットが同じ居住スペースで過ごせることは分けて考えます。**

平常時に確認したいのは、

- 自宅から行く可能性がある避難所
- ペット同行の可否
- ペットの飼養場所
- ケージ等の条件
- 必要な持参品
- 車中避難等を安易な代替にしないこと
- 避難所が使えない場合の一時預け先

です。

災害発生後は情報が変わる場合があるため、実際の避難時には自治体・避難所の最新案内を優先します。

## フード・水は「少なくとも5日、できれば7日以上」を一つの目安にする

広島県は、ペットフードと水について**少なくとも5日分、できれば7日分以上**を飼い主側で準備するよう案内しています。

家庭で数えるときは、

- 1日あたりの普段の給餌量
- 1日あたりの飲水量
- ペットの頭数
- 何日分を持つか

に分けます。

例えば、1日2袋使うフードを7日分用意するなら14袋です。ただし、必要量は種類・体格・年齢・健康状態で変わるため、**商品パッケージや獣医師の指示を優先**します。

療法食や常用薬が必要なペットでは、一般的なフードで代用できるとは限りません。予備をどの程度用意できるかは、平常時にかかりつけの動物病院へ相談します。

## 命・健康に関わる物を先にまとめる

持ち出し品を全部同じ優先度で扱うと、バッグやケージ周辺がかさばります。まず代替しにくい物をまとめます。

| 優先度 | 例 | 理由 |
|---|---|---|
| 高 | フード、水、常用薬、療法食 | 健康状態に直接関わる |
| 高 | キャリー/ケージ、首輪、リード | 安全に移動・管理するため |
| 高 | トイレ用品、排泄物処理用品 | 避難生活の衛生維持 |
| 中 | 写真、健康情報、連絡先 | はぐれた場合や診療時に役立つ |
| 補助 | タオル、ブラシ、使い慣れた玩具 | ストレス軽減やケア |

**重くなりすぎる場合も、療法食や薬など本人に代わりがきかない物から削らない**ようにします。

## 犬と猫では追加したい物が少し違う

共通用品に加えて、普段の生活に合わせて追加します。

### 犬

- 予備の首輪
- 伸びないリード
- 排泄物処理袋
- 必要に応じて食器
- 鑑札・迷子札等の身元確認手段

### 猫

- 十分な強度のキャリー
- 使い慣れた猫砂
- 猫用トイレ
- 排泄物処理袋
- 必要に応じて洗濯ネット等

猫は普段と違う砂や環境で排泄しにくくなる場合があるため、**使い慣れた用品を備蓄へ入れる**考え方が実用的です。

## キャリーやケージは「災害時に初めて使う」にしない

環境省と広島県は、ペットをキャリーやケージへ入れることに普段から慣れさせる重要性を案内しています。

購入して保管するだけではなく、

1. 普段から部屋に置く
2. 自分から入れるようにする
3. 短時間扉を閉める
4. 持ち上げて移動する
5. 避難経路を想定して玄関まで移動する

と段階的に確認します。

無理に押し込んで強い恐怖を与えるのではなく、日常生活の中で少しずつ慣らします。しつけや強い不安がある場合は、動物病院等へ相談します。

## 写真と健康情報を「紙とスマホ」の両方に残す

避難中にはぐれたり、いつもの動物病院へ行けなかったりする可能性があります。

次の情報をまとめます。

- ペットの最近の写真
- 飼い主の氏名・連絡先
- ペットの名前、種類、年齢
- 既往歴
- 常用薬・療法食
- ワクチン等の健康情報
- かかりつけ動物病院
- 一時預け先候補

スマートフォンだけに保存すると電池切れや故障時に見られないため、**簡単な紙の連絡カードもキャリーや持ち出し袋に入れる**と確認しやすくなります。

## 一時預け先を1か所だけにしない

自宅も避難所もペットの飼養に適さない場合があります。

平常時に、

- 親族・知人
- ペットホテル
- かかりつけ動物病院
- 地域の一時預かり制度

などを確認します。

実際に利用できるかは災害規模や相手側の被災状況にも左右されます。**1か所を必ず使える前提にせず、候補を複数持つ**方が現実的です。

## 避難時は人の安全を先に確保する

ペットを助けるために、危険な建物へ戻る、浸水した道路へ入る、強風中に外へ出るといった行動は避けます。

環境省も、災害時にまず飼い主自身や家族の安全を確保することを前提としています。

- 避難情報
- 建物の安全
- 火災・津波・浸水等
- 移動経路

を確認し、危険な状況では人命を優先します。

## 保存用チェックリスト

- [ ] ペット用フード・水を数えた
- [ ] 常用薬・療法食の準備方法を確認した
- [ ] キャリー/ケージに普段から慣れている
- [ ] 首輪・リード等が劣化していない
- [ ] ペットシーツ・猫砂等を準備した
- [ ] 排泄物処理袋を準備した
- [ ] 最近の写真を保存した
- [ ] 健康情報・動物病院連絡先をまとめた
- [ ] 自治体の同行避難ルールを確認した
- [ ] 一時預け先候補を複数考えた
- [ ] 家族で誰がペットを連れて動くか決めた

## 今日15分でやるなら

全部そろえる前に、次の3つを先に行います。

1. 自治体サイトで「ペット 同行避難」を確認する
2. フード・水が今何日分あるか数える
3. キャリーを出して、ペットが入れる状態か確認する

その後、薬・トイレ用品・健康情報・一時預け先へ広げます。
