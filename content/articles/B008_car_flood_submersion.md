# 車が冠水・水没しそうなときに知っておきたいこと

大雨時の車で最も重要なのは、**冠水した道路へ入らないこと**です。

冠水路は、水深だけでなく路面の陥没、マンホール、側溝、流れの速さなどが見えません。車種や速度によって浸水の影響も変わるため、見た目から「この程度なら走れる」と判断するのは危険です。

国土交通省も、自動車は深い水の中を走行できるようには設計されておらず、冠水した道路へ安易に進入しないこと、動けなくなった場合は早めに脱出することを案内しています。

## 1. 冠水路を見つけたら、進入せず迂回する

JAFの冠水路走行テストでは、同じ水深でも車種や速度によって結果が変わり、走り切れたケースでも車内やエンジンルームへ水が入る例があります。

実際の道路ではテスト環境と違い、

- 水深が一定ではない
- 路面が見えない
- 流れがある
- 穴や段差がある
- マンホールのふたが外れている可能性がある
- 前方でさらに深くなっている可能性がある

ため、**テスト結果を「走行できる水深の基準」として使わない**ことが重要です。

前方に冠水を見つけたら、停止できる段階で引き返すか、安全な別ルートへ迂回します。

## 2. 特にアンダーパス・低い道路を避ける

アンダーパス、高架下、周囲より低い道路は、短時間の大雨でも水が集まりやすい場所です。

普段は何度も通っている道路でも、豪雨時には状況が変わります。国土交通省や道路管理者が冠水想定箇所を公表している地域もあるため、普段使う経路に低い場所がないか確認しておきます。

注意したい場所は、

- アンダーパス
- 高架下
- 河川沿い
- 海沿い
- 地下駐車場の出入口
- 周囲より低い交差点
- 過去に冠水した道路

です。

**大雨が始まってから迂回路を探すのではなく、平常時に代替ルートを決めておく**と判断しやすくなります。

## 3. 「床面までなら大丈夫」という意味ではない

国土交通省は、水深が車両の床面を超えると、車内への浸水や電気装置の故障、エンジン・モーターの停止等のおそれがあるとしています。

また、水深が床面より低くても、走行速度によって巻き上げた水がエンジン等へ入り、不具合につながる場合があります。

さらに、

- 水流があると車両が流されるおそれがある
- タイヤが完全に水没すると車体が浮くおそれがある
- 車高や設計によって影響が異なる

とされています。

したがって、**「床面より下なら走行可能」という安全基準ではありません。** 数値を進入判断に使わず、冠水路を避けることを前提にします。

## 4. 車内へ水が入り始めたら、動けなくなる前に脱出を考える

冠水路へ入ってしまい、車内へ水が入り始めた場合は、車が完全に停止するまで様子を見るのではなく、早めに脱出を判断します。

国土交通省は、水位が上がると、

- 電装系が故障してパワーウインドウが動かなくなる
- 外側の水圧によってドアが開けにくくなる
- 車体が浮いたり流されたりする

可能性を示しています。

JAFも、水没時はまず落ち着いてシートベルトを外し、窓が水面より高い位置にあり開けられる場合は窓から脱出するよう案内しています。

ただし、外へ出た先の水流や水深が危険な場合もあります。**「車内にいる危険」と「車外へ出る危険」の両方がある**ため、可能なうちに状況を確認し、切迫する前に行動することが重要です。

## 5. 水没時の脱出手順を事前に知っておく

国土交通省が示している考え方を整理すると、基本的な流れは次のとおりです。

1. **シートベルトを外す**
2. **開けられるうちにドアまたは窓から脱出する**
3. ドアも窓も開かない場合は、破砕可能な窓を緊急脱出用ハンマーで割る
4. それでも開口部を確保できない場合、水位差が小さくなってドアが開けられる状態になる場合があるため、最後まで脱出を試みる

4番目は、意図的に車内へ残ることを勧めるものではありません。**前の段階で脱出できるうちに脱出することが優先**です。

緊急時に手順を初めて読む余裕はありません。運転者だけでなく、普段同乗する家族も「シートベルトを外す」「窓を使う」「ハンマーの場所を知る」程度は共有しておきます。

## 6. 脱出用ハンマーは「持っているだけ」では不十分

国土交通省は、水没等で閉じ込められた場合に備え、緊急脱出用ハンマーを手の届く場所に固定し、使用方法をあらかじめ確認するよう案内しています。

確認したいのは、

- 運転席から手が届く場所にあるか
- 固定されていて衝撃で飛ばないか
- シートベルトカッターの有無
- どのガラスを破砕できるか
- 製品の使用方法を理解しているか

です。

グローブボックスの奥や荷室など、**閉じ込められた状態で届かない場所では意味がありません**。

### フロントガラスや一部のドアガラスは割れない

フロントガラスは一般に合わせガラスで、脱出用ハンマーで破砕して開口部を作る用途には使えません。

また、一部の車種ではドアガラスにも合わせガラスが採用されています。国土交通省とJAFはいずれも、**自分の車で破砕可能な窓を事前に確認すること**を案内しています。

車種・年式・仕様によって異なるため、取扱説明書、メーカー、販売店等で確認します。

## 7. スマートフォンや鍵を「代用ハンマー」と考えない

JAFのユーザーテストでは、スマートフォン、傘、車のキー、硬貨、ヘッドレスト等の身近な物では、テストした強化ガラスを破砕できませんでした。一方、専用の緊急脱出用ハンマーでは破砕できました。

これはすべての車・すべての条件で同じ結果になることを保証するものではありませんが、**日用品を脱出器具の代わりとして当てにしない**理由になります。

専用品を用意する場合も、製品の性能・適合・使用方法を確認します。

## 8. 複数人で乗る家庭は、誰が何をするか考えておく

子ども、高齢者、体の不自由な人などが同乗する場合、運転者自身が脱出できても、同乗者の支援が必要になることがあります。

平常時に、

- 誰が子どものシートベルト等を外すか
- 脱出用ハンマーを誰でも見つけられるか
- 後席から手が届く脱出口はどこか
- チャイルドシート等を使用している場合、解除方法を理解しているか

を確認します。

災害時の状況は毎回異なるため、固定した「脱出順」を決めるというより、**車内設備の解除方法と脱出口を家族で知っておく**ことを目的にします。

## 9. 水が引いた後も、エンジンを始動しない

一度浸水した車両は、見た目では問題がなくても、

- 電気装置
- エンジン・モーター
- ブレーキ
- センサー
- 配線

等が損傷している可能性があります。

国土交通省は、水が引いた後もエンジンをかけず、浸水した車両は点検整備を受けるよう案内しています。

特にEV、PHEV、HVは高電圧バッテリーを搭載しているため、**自分で高電圧系統へ触れず、整備工場や販売店等へ相談**します。

「水が引いた」「メーターが点く」ことを理由に自走しようとしないことが重要です。

## 10. 被害後は安全を確保してから記録・連絡する

車が浸水した場合は、自分や同乗者の安全を最優先にします。

安全な場所へ移動できた後に、

- 車両の位置
- 浸水した高さが分かる状況
- 車内外の被害
- 周辺の冠水状況

を無理のない範囲で写真に残すと、後の修理や保険確認時に状況を説明しやすくなります。

ただし、**撮影のために冠水路へ戻ったり、流れのある水へ近づいたりしない**でください。ロードサービス、販売店、保険会社等への連絡方法を平常時に確認しておくと、被災後の判断がしやすくなります。

## 11. 大雨前にできる車の準備

- 冠水しやすい道路とアンダーパスを確認する
- 代替ルートを決める
- 地下・低地の駐車場所を確認する
- 脱出用ハンマーを手の届く場所へ固定する
- 自分の車の破砕可能なガラスを確認する
- シートベルトカッター等の使用方法を確認する
- 同乗者と脱出方法を共有する
- ロードサービス・販売店等の連絡先を確認する
- 大雨時の不要不急の運転を避ける

関連する商品記事:
- 車に積んでおきたい防災用品｜車載用に考える（B029・準備中）

脱出用ハンマー等の具体商品は、車種ごとのガラス仕様や製品適合を確認して選びます。安全手順より商品購入を優先しません。

## やってはいけないこと

- 前の車が通ったからと冠水路へ続いて進入する
- 「SUVだから大丈夫」など車種だけで判断する
- 水深の目安を安全基準として使う
- 車が停止するまで車内で様子を見る
- ハンマーが荷室にあるだけで備えたつもりになる
- フロントガラスをハンマーで割ろうとし続ける
- 水没後にエンジンを試しに始動する
- 写真撮影のため危険な場所へ戻る

## 状況別の優先行動

| 状況 | 優先すること |
|---|---|
| 冠水路を前方に発見 | 進入せず迂回 |
| 低い道路へ入る前 | 別ルートを選ぶ |
| 車内へ浸水開始 | 早めの脱出を判断 |
| ドアが開く | 早期に脱出 |
| 窓が動く | 脱出口として使う |
| ドア・窓が開かない | 破砕可能な窓と専用ハンマーを使用 |
| 水が引いた後 | 始動せず専門家へ相談 |

## まとめ

車の冠水・水没対策は、脱出方法を覚えること以上に、**冠水した道路へ入らないこと**が重要です。

大雨時はアンダーパスや低い道路を避け、普段から代替ルートと駐車場所を確認します。万一車内へ水が入った場合は、窓やドアを使えるうちに脱出を判断し、脱出用ハンマーの位置と対応ガラスも平常時に確認しておきます。

水没後は車を再始動せず、ロードサービス、整備工場、販売店等へ相談します。
