# 防災リュックは何L必要？容量より先に中身と重さを確認する

防災リュックを選ぶとき、「20L・30L・40Lのどれがよいか」と容量から考えたくなります。しかし、公的な防災資料は非常持ち出し品をリュック等に入れて準備することを案内している一方、**家庭向けに一律の正解容量を示しているわけではありません。**

先に必要な中身と自分が持てる重さを決め、その荷物が無理なく収まるバッグを選ぶ方が実用的です。

## 結論：L数より「中身→重さ→容量」の順で決める

防災リュックは次の順で選びます。

1. 避難時に本当に持ち出す物を決める
2. 自宅備蓄と分ける
3. 実際の荷物を一度集める
4. 背負って移動できる重さか確認する
5. その荷物が収まる容量・形状のバッグを選ぶ

**大きいリュックを先に買い、空いている分まで荷物を足す**のは逆の考え方です。

## まず「自宅に置く物」を外す

内閣府は、食料・飲料水は最低3日分、できれば1週間分を備える一方、急いで避難する場合に「すぐ必要になるもの」「ないと困るもの」を非常持ち出し品としてリュック等へ入れておく考え方を示しています。

つまり、1週間分の水や食料を全部リュックへ入れる必要はありません。

| 自宅備蓄 | 持ち出し品 |
|---|---|
| 数日〜1週間の水・食料 | 避難直後に必要な飲料・食品 |
| まとまった携帯トイレ | 移動中・避難先用の少量 |
| 大容量の生活用品 | 最低限の衛生用品 |
| 予備の電源・電池 | 必要な充電手段 |

中身の基本は[防災リュックの中身の記事](article_b002.html)で先に確認できます。

## 20L・30L・40Lという数字だけでは決まらない

同じ「30L」と表示されたリュックでも、形、開口部、ポケット、背面構造などが異なるため、同じ荷物が同じように入るとは限りません。

見るポイントは容量表示だけではありません。

- 開口部が大きく、中身を取り出しやすいか
- 水や重い物を背中側へ寄せやすいか
- 肩紐を体格に合わせて調整できるか
- 必要品を小分けできるか
- 雨への対策ができるか
- 背負った状態で両手を使えるか

L数は候補を絞るための情報として使い、**最終判断は実際の中身を入れた状態**で行います。

## 1人用・2人用は「人数分を1袋」にしなくてもよい

「2人用だから大きなリュック1個」と考える必要はありません。

家族で避難する場合は、

- 飲料水
- 食品
- ライト
- モバイルバッテリー
- 衛生用品

などを分担できます。

一方、薬、眼鏡、乳幼児用品など、**特定の人に欠かせない物は本人側の荷物として分ける**方が、バッグが別になったときにも確認しやすくなります。

子どもや高齢者へ一律の荷物量を割り当てず、体力・移動距離・階段・介助の必要性に合わせます。

## 大きすぎるバッグにも注意する

容量に余裕があると「これも入れておこう」と荷物が増えやすくなります。

防災リュックでは、空間を埋めることより、

- 背負って立てる
- 数分歩ける
- 階段を使える
- 両手を使える
- 必要な物をすぐ取り出せる

ことを優先します。

バッグが大きくても、中身を必要最小限にできていれば問題ありません。逆に、小さなバッグでも詰め込みすぎて使いにくければ見直します。

## 小さすぎるときは「必要品を削る」のではなく役割を分ける

必要な薬や衛生用品を無理に減らしてバッグへ合わせるのは避けます。

入りきらないときは、

1. 自宅備蓄まで入れていないか
2. 同じ用途の物が重複していないか
3. 家族で分担できないか
4. 車載備蓄など別の場所へ分けられないか

を確認します。

それでも必要品が入らなければ、より大きいバッグを検討します。

## 実際に詰めて「避難テスト」をする

消防庁は、非常持ち出し品を持ち出しやすい場所に置き、背負える袋等に入れて両手を使えるようにする考え方を案内しています。

購入後は、棚に置いて終わりにせず、

- 全部入れた状態で背負う
- 家の中を歩く
- 階段を使う
- 玄関まで持って行く
- 必要な物を取り出して戻す

ところまで試します。

この確認で重すぎる場合は、容量を変える前に中身を見直します。

## 容量選びチェックリスト

- [ ] 自宅備蓄と持ち出し品を分けた
- [ ] 必要品を先に並べた
- [ ] 家族固有の薬・衛生用品を確認した
- [ ] 実際の荷物をバッグに入れた
- [ ] 背負って数分歩いた
- [ ] 階段や玄関までの動線を確認した
- [ ] 両手を使える
- [ ] 中身を取り出しやすい
- [ ] 大きさに合わせて不要品を追加していない
- [ ] 家族で荷物の分担を決めた

## 20L・30Lなどを検索するときの見方

商品を探す段階では、容量だけでなく次の項目を一緒に確認します。

| 表示 | 一緒に確認したいこと |
|---|---|
| 容量（L） | 実寸、形状、開口部 |
| 本体重量 | 中身を入れた総重量 |
| ポケット | 必要品の取り出しやすさ |
| 肩紐 | 調整範囲・体格への適合 |
| 防水・撥水表記 | 製品が示す条件・カバーの有無 |

特定の容量を「この人数なら必ず十分」とは決めず、**持ち出す中身と本人の体格に合わせて確認**します。
