# 高齢者の防災は何を準備する？薬・補聴器・入れ歯・避難支援を確認

高齢者がいる家庭では、一般的な水・食料・防災リュックに加えて、**常用薬の情報、眼鏡・補聴器・入れ歯、介護食・排泄用品、歩行補助具、誰が避難を支援するか**まで確認します。

「高齢者向け防災グッズを一式そろえる」より、本人にとって**代替しにくい物と、避難に必要な人・情報**を先に整理する方が実用的です。

## 結論：物と支援を4つに分ける

1. **医療・健康**：常用薬、お薬手帳、主治医・薬局情報
2. **生活機能**：眼鏡、補聴器、入れ歯、杖、排泄用品
3. **食事**：食べ慣れた食品、介護食、飲み込み等に配慮した食品
4. **避難支援**：避難先、家族・近隣・支援者、自治体制度

特に薬・補聴器・眼鏡など、**無いと日常動作や避難そのものが難しくなる物**を優先します。

## 常用薬は「何の薬を飲んでいるか」が分かる状態にする

薬の予備量を自己判断で増減するのではなく、まず薬の情報を確認できるようにします。

- 薬の名前
- 用法・用量
- 処方している医療機関
- 利用している薬局
- お薬手帳
- アレルギー・副作用歴等の重要情報

広島県は、疾患のある人の持ち出し品として主治医連絡先、持病薬、お薬手帳を挙げています。厚生労働省も紙・電子のお薬手帳を薬歴管理に使える仕組みとして案内しています。

**災害用として薬を何日分追加できるかは、薬の種類や処方条件によって異なります。**平常時に医師・薬剤師へ確認し、自己判断で服用量を変えません。

## お薬手帳は「紙かスマホか」ではなく、確認できる状態を複数持つ

電子版お薬手帳は持ち運びやすい一方、停電・通信障害・端末故障も考えられます。

可能なら、

- 普段のお薬手帳
- 電子版お薬手帳
- 薬名・用法の簡単な紙メモ

など、複数の確認方法を用意します。

すべてを新しく作り直す必要はありません。**「本人以外の人が薬の情報を確認できるか」**を基準にします。

## 眼鏡・補聴器・入れ歯は一般の防災リストから抜けやすい

広島県の持ち出し品案内では、高齢者向けに入れ歯・洗浄液、介護食、大人用おむつ、杖、その他として眼鏡・補聴器等を挙げています。

本人が普段使っている物から確認します。

| 用途 | 確認する物 |
|---|---|
| 視覚 | 眼鏡、必要に応じて予備、眼鏡ケース |
| 聴覚 | 補聴器、充電手段・対応電池、保管ケース |
| 口腔 | 入れ歯、洗浄用品、保管容器 |
| 移動 | 杖、歩行補助具、履き慣れた靴 |
| 排泄 | 大人用おむつ、尿取りパッド、処理袋 |

新しい補助具を災害用だけに用意する場合も、**本人が実際に使えるかを平常時に確認**します。

## 入れ歯・口腔ケア用品も「食べるための道具」として備える

農林水産省の要配慮者向け食品ストックでは、高齢者の備蓄品として入れ歯・入れ歯洗浄剤等が挙げられています。

避難生活では水不足等で口腔ケアが難しくなる場合があります。広島県も、歯・口・入れ歯の清掃用品を使って口腔衛生を保つことを案内しています。

- 入れ歯
- 洗浄剤
- 保管容器
- 歯ブラシ等
- 必要に応じて少量の水でも使える口腔ケア用品

を本人の普段のケア方法に合わせて準備します。

## 食品は「長期保存」より、本人が食べられるかを先に見る

農林水産省は高齢者向け備蓄例として、

- レトルト・アルファ米のおかゆ
- 缶詰・レトルト食品
- フリーズドライ食品
- 即席スープ等
- 食べ慣れた乾物
- 栄養補助食品
- 好物の食品・飲み物

を挙げています。

噛む・飲み込む機能が弱くなっている場合には、やわらかいレトルトごはん、介護食品、とろみ調整食品等も別に紹介されています。

ただし、**「高齢者だから全員おかゆ」「とろみを付ければ安全」とは決めません。**本人が普段食べている形態や、医療・介護職から受けている指示を優先します。

## 水・食料は本人だけ別の場所に隠さない

食事に配慮が必要な場合、家族や支援者が「どれを使うか」分からないと災害時に困ります。

- 本人用の食品をまとめる
- 名前を付ける
- 食べ方・注意点を簡単に書く
- 家族や支援者へ保管場所を共有する

と、本人以外でも確認しやすくなります。

## 避難に時間がかかる場合は「誰が、どこへ」を先に決める

内閣府は、災害時に自ら避難することが困難な高齢者・障害者等を「避難行動要支援者」とし、名簿・個別避難計画の取組を進めています。

個別避難計画は、対象となる避難行動要支援者について、**誰が避難を支援するか、どこへ避難するか等を個別に整理するための計画**です。

ただし、

- 高齢者なら全員が対象とは限らない
- 対象基準は自治体の制度による
- 計画の作成状況・進め方は自治体で異なる
- 支援者が必ず来られることを保証する制度ではない

ため、住んでいる市区町村へ確認します。

## 個別避難計画は「作ってあるか」だけで終わらせない

市町村の個別避難計画作成は、災害対策基本法上の努力義務として進められています。

本人・家族側では、

- 自分が対象になるか
- 計画が作成済みか
- 避難先は現在も適切か
- 支援者・連絡先は変わっていないか
- 使用する移動手段は現実的か

を確認します。

身体状態、住居、介護サービス、家族構成が変わった場合は、自治体や関係者へ相談します。

## 一人暮らし・昼間独居なら「家族以外の連絡先」も考える

家族が遠方にいる、昼間は一人になるなどの場合は、家族だけを支援者候補にすると連絡が遅れる可能性があります。

本人の状況に応じて、

- 近隣の親族・知人
- 民生委員等
- ケアマネジャー等の福祉関係者
- 利用している介護サービス事業者
- 自治体窓口

など、**平常時に実際に関係がある人・機関**を確認します。

新たな個人情報共有は本人の同意や自治体・事業者のルールに従います。

## 持ち出し品は「本人が持つ物」と「支援者が運ぶ物」を分ける

全部を本人のリュックへ詰める必要はありません。

| 本人がすぐ使う | 家族・支援者と分担する |
|---|---|
| 眼鏡・補聴器 | まとまった飲料水 |
| 常用薬・薬情報 | 数日分の食品 |
| 杖等の移動補助 | 予備の排泄用品 |
| 連絡カード | 追加の着替え・生活用品 |

本人が持つバッグは、**立つ・歩く・杖を使う・手すりを持つ等の動作を妨げない**重さにします。

## 保存用チェックリスト

- [ ] 常用薬とお薬手帳の場所を確認した
- [ ] 主治医・薬局の連絡先を確認した
- [ ] 眼鏡・補聴器・入れ歯等を持ち出せる
- [ ] 補聴器の充電・電池を確認した
- [ ] 杖・歩行補助具が使える状態にある
- [ ] 大人用おむつ等の排泄用品を準備した
- [ ] 本人が食べられる食品を備蓄した
- [ ] 食事形態・アレルギー等を家族が把握している
- [ ] 避難先を確認した
- [ ] 誰が避難を支援するか話した
- [ ] 自治体の避難行動要支援者制度を確認した
- [ ] 個別避難計画がある場合は内容を見直した
- [ ] 家族以外の連絡先も確認した

## 今日15分でやるなら

1. お薬手帳・眼鏡・補聴器等を1か所ずつ確認する
2. 避難先まで本人がどのように移動するか話す
3. 自治体サイトで「避難行動要支援者」「個別避難計画」を検索する
