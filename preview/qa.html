車と災害

5件のQ&A

水害で車が壊れたんですが、保険はおりますか？

個別の支払可否は車両保険の契約内容によります。保険証券・約款を確認し、保険会社や代理店へ事故状況を伝えて確認してください。

関連: 水没した車は車両保険の対象？ 準備中 / 車の冠水・水没
水没した車は、エンジンをかけて確認してもいいですか？

浸水した車は、見た目に問題がなくても電装系やエンジン等が損傷している可能性があります。点検前に始動せず、販売店・整備工場・ロードサービス等へ相談します。

関連: 車の冠水・水没
冠水した道路は何cmくらいまでなら走れますか？

安全に走行できる一律の水深として考えない方がよいです。水深だけでなく流れ、路面の穴、段差、車種、速度等で危険が変わるため、冠水路には進入せず迂回します。

関連: 車の冠水・水没 / 冠水路を走る危険 準備中
車に脱出用ハンマーを積んでおけば安心ですか？

持っているだけでは不十分です。運転席から届く場所へ固定し、自分の車で破砕可能な窓を事前に確認します。フロントガラスや一部のドアガラスは合わせガラスの場合があります。

関連: 車の冠水・水没 / 車載防災用品 準備中
大雨の前に車を別の場所へ移した方がいいですか？

地下・半地下、河川沿い、低地など駐車場所の浸水リスクを確認します。移動する場合も、風雨が強くなる前の安全な段階で判断し、避難が遅れた後に車だけを優先しません。

関連: 地下駐車場・低い場所の大雨対策 準備中 / 台風前の家庭チェック

住宅・保険

5件のQ&A

自宅が床上浸水しました。火災保険は使えますか？

水災補償の有無や支払条件は契約によって異なります。床上浸水という事実だけで一律に判断せず、保険証券・約款を確認して保険会社・代理店へ連絡します。

関連: 火災保険の水災補償
浸水した家具や家電も火災保険の対象ですか？

建物と家財は別の保険対象です。家財の契約内容と水災補償の有無を確認する必要があります。

関連: 浸水した家財と保険 準備中 / 火災保険の水災補償
賃貸住宅が浸水しました。自分の保険でどこまで見てもらえますか？

建物自体と入居者が所有する家財は分けて考えます。自分の家財契約を確認し、建物や共用部分については管理会社・所有者等にも確認します。

関連: 火災保険の水災補償 / 家財の水災補償 準備中
浸水後、片付ける前に写真を撮った方がいいですか？

安全が確保できる場合は、建物や家財の全体と、浸水高さ・損傷箇所が分かる写真を残すと状況説明に役立ちます。ただし、撮影のため危険な建物へ戻ることは避けます。

関連: 片付け前に記録したいもの 準備中 / 火災保険の水災補償
ハザードマップで色が付いていなければ水害は大丈夫ですか？

色が付いていないことを「絶対に安全」とは考えません。想定条件を超える雨や、地図で表現しきれない局地的な浸水もあり得るため、自治体の最新情報や地形も確認します。

台風・大雨・避難

5件のQ&A

台風対策はいつから始めればいいですか？

屋外の片付けや窓・雨戸の確認などは、風雨が強くなる前に終えるのが基本です。進路が気になり始めた段階から、備蓄・避難先・家族予定を順に確認します。

関連: 台風前の家庭チェック / 台風前日のチェック 準備中
窓にテープを貼れば台風でも割れませんか？

テープを貼るだけで窓が割れなくなるとは断定できません。雨戸・シャッターの動作確認や、窓際から割れ物・家具を離すことなど、住宅設備に合った対策を確認します。

関連: 台風前の家庭チェック
避難するときは必ず指定避難所へ行く必要がありますか？

避難は生命・身体を守るための行動です。指定緊急避難場所だけでなく、安全な親族・知人宅や、条件を満たす場合の屋内安全確保なども含め、災害と現在地に応じて事前に考えます。

関連: 大雨・水害の基本
大雨のとき、家族が外出中なら一度家に集合した方がいいですか？

必ず自宅へ戻ることが安全とは限りません。現在地が安全なら無理な移動を避け、家族が別々に避難した場合の連絡方法や集合場所を平常時に決めておきます。

関連: 大雨・水害の基本 / 台風前の家庭チェック
大雨のときは何の情報を見ればいいですか？

気象庁の防災気象情報やキキクル、自治体の避難情報、河川・道路情報、ハザードマップなどを組み合わせて確認します。一つの通知だけに依存しないことが重要です。

停電・断水・備蓄

5件のQ&A

飲料水は何日分くらい備蓄すればいいですか？

政府の家庭向け案内では、食料・飲料水は最低3日分、できれば1週間分の備蓄が示されています。家族人数や生活条件に合わせて無理なく増やします。

関連: 飲料水の備蓄 準備中 / 防災の基本
携帯トイレは何回分あればいいですか？

家族人数、想定する断水日数、1人あたりの使用回数をもとに考えます。必要数だけでなく、保管場所や使い方も事前に確認しておくことが重要です。

関連: 携帯トイレの備え 準備中 / トイレ・衛生用品
停電対策は何から準備すればいいですか？

まず「照明」「情報収集」「スマートフォン等の充電」を分けて考えると整理しやすくなります。そのうえで水・食品・トイレなど、停電と同時に困る生活用品も確認します。

関連: 停電への備え 準備中 / ライト・ラジオ / 電源・充電
スマートフォンがあれば防災ラジオはいりませんか？

スマートフォンは重要な情報手段ですが、停電・充電切れ・通信障害も考えます。家庭の状況に応じて、ラジオ等の別手段を持つか検討します。

関連: 防災ラジオは必要？ 準備中 / ライト・情報用品
ポータブル電源は防災に必要ですか？

必須とは限りません。停電時に何へ何時間給電したいかを先に整理し、モバイルバッテリーで足りるのか、より大きな電源が必要なのかを判断します。

関連: ポータブル電源は必要？ 準備中 / 電源・充電用品

防災バッグ・防災用品

5件のQ&A

防災バッグは何kgまでなら大丈夫ですか？

誰にでも当てはまる安全な上限重量はありません。目安の数字だけで決めず、実際に背負って歩けるか、階段を移動できるかなどを確認します。

関連: 防災バッグの基本
自宅の備蓄を全部、防災バッグに入れた方がいいですか？

自宅備蓄と避難時の持ち出し品は役割が異なります。防災バッグは、避難時に実際に持てる範囲で「すぐ必要になるもの」を優先します。

関連: 防災バッグの基本
非常食は専用品だけを買った方がいいですか？

防災専用品だけに限定する必要はありません。普段食べている保存しやすい食品を入れ替えながら備える方法もあります。

関連: 非常食の備蓄 準備中 / 水・非常食
車にはどんな防災用品を積んでおけばいいですか？

車で想定する困りごとから逆算します。ライト、連絡・充電手段、飲料水、衛生用品、季節用品、車両脱出用品などを候補にし、車内温度や保管条件にも注意します。

関連: 車載防災用品 準備中 / 車の冠水・水没
防災用品は最初に一式セットを買った方がいいですか？

セットが便利な場合もありますが、家庭ごとに必要品は異なります。先に必要な用途を整理し、不足している物だけ追加する方が中身を把握しやすくなります。
